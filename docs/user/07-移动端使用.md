# 移动端使用

手机浏览器打开同一个地址，OpenCloth 会换成触摸界面：一块全屏的 3D 试衣视口，加上一条动作坞和几个抽屉。章节顺序依次为：支持的设备与界面组成（§1、§2）、手势与一次完整试衣（§3、§4）、菜单分组、手机缺失的功能与常见问题（§5–§7）、下一步（§8）。

## 1. 支持的浏览器与设备

| 端 | 要求 |
| --- | --- |
| Android | Android 12 及以上，Chrome 121+（需高通或 ARM GPU） |
| iPhone / iPad | iOS / iPadOS 26 的 Safari 26（iPad 按平板规则使用电脑界面） |
| 电脑 | Chrome 113+ / Edge 113+（与桌面端相同） |

判定规则是**主指针为触摸、屏幕短边不超过 560 CSS 像素**：手机横屏竖屏都算手机，平板与窄窗口仍使用电脑界面。屏幕更大些的设备想用触摸界面，在地址后面加 `?ui=mobile`；反过来让触摸设备用电脑界面，加 `?ui=desktop`。

> **注**：没有 WebGPU 的手机会停在【当前浏览器不支持 WebGPU】页面。应用没有第二套渲染后端，光栅化与布料模拟都在 WebGPU 上运行。

## 2. 界面

从上到下三段：顶栏、视口、动作坞。横屏时动作坞会贴住屏幕底部，刘海与手势条区域都留了安全边距。

### 2.1 顶栏

顶栏第一行左侧是【菜单】按钮，中间是当前工程名，右侧是性能读数 `FPS 58` 或 `SPP 12/64`，再后面跟 `帧 218`；分子为 0 时，读数后写明当前受哪一项限制：【光追内核加载中】 / 【布料每帧在变】 / 【视角未静止】 / 【光栅过渡中】 / 【本机不支持】。第二行左侧是模拟状态：【未着装】、【缝合着装中】、【模拟中】、【已暂停】，右侧是选中提示：没有选片时写 `轻点布料选片 · 参数`，选中某张片后写 `选中 前片 · 参数`，点这里直接打开参数抽屉。

### 2.2 视口与浮动按钮

视口独占整块画面，底部一行提示当前支持的手势。右下角竖排三个圆钮：

- 【视角】：十个方位预设、透视 / 正交投影，以及【构图】里的【适应当前视角】（与右下角圆钮【适应】等效）。
- 【显示】：光栅化 / 光线追踪 / 线框 / UV 检查 / 法线可视化 / 合身热图。这台设备的 WebGPU 无法运行光追内核时，【光线追踪】会置灰成 `光线追踪（不支持）`并在下面写明原因。选中【合身热图】后，下方出现【贴近阈值】与【宽松阈值】两条滑块，以及穿透 / 贴近 / 合适 / 宽松数量与最小 / 平均 / 最大间隙读数；选回其它显示模式即恢复面料材质。
- 【适应】：按场景整体大小取景。

### 2.3 动作坞

底部五个按钮，自左至右依次是：

- 【自动着装】：依次经过缝合收拢 → 贴体 → 零重力松弛三个阶段，着装中显示 `着装中…` 并置灰。
- 【播放】 / 【暂停】：切换模拟运行。
- 【重置】：回到初始状态。
- `1/60 s`（步长）：按钮上显示当前步长，每按一次换一档，依次是 `1/30 s`、`1/60 s`、`1/120 s`、`1/240 s`；非默认档时按钮描蓝边。档位含义见 [04-布料模拟](./04-布料模拟.md) §1.2。
- 【参数】：打开属性抽屉。

### 2.4 抽屉

一次只开一个，从底部升起，点遮罩、点【关闭】或按 Esc 收起。四个抽屉：【菜单】、【视角】、【显示】、【参数】。【参数】顶部是横排标签【对象】、【材质】、【模拟】、【变换】、【渲染】、【工程】，与电脑端属性编辑器是同一批控件，只是尺寸放大到能用手指点按。

## 3. 手势

| 手势 | 作用 |
| --- | --- |
| 单指拖拽 | 旋转视角 |
| 双指捏合 | 缩放 |
| 双指同时拖动 | 平移 |
| 轻点布料 | 选中那张版片 |
| 轻点空白 | 取消选中 |

> **注**：手机上没有【打PIN】与【拔PIN】，模拟里因此没有固定点；触摸也没有悬停，所以「捏住布料拖拽」只在电脑端可用，手机上单指拖拽仍然是旋转视角。需要固定某处或拨着布料看褶皱时回电脑端操作。

## 4. 在手机上完成一次试衣

1. 打开地址，等【正在初始化 WebGPU 渲染器…】结束，画面里是模特与环绕在外的版片，顶栏状态为【未着装】。
2. 点【自动着装】，约一秒钟后状态转成【模拟中】，布料下垂贴合模特并形成褶皱。
3. 单指旋转、双指缩放，从不同角度查看；要正面构图就点【视角】抽屉里的【正视】。
4. 轻点某张片（例如前片），点【参数】换颜色与光泽，或到【模拟】标签改弯曲刚度与克重，改动立刻作用在正在运行的模拟上。
5. 想存下来：【菜单 → 导出 → 截图 PNG】；【菜单 → 工程 → 保存】会下载 `.ocproj.json`，之后可以在电脑上打开继续改版型。

## 5. 菜单抽屉的分组

【菜单】抽屉把电脑端的五个下拉合并为一列分组，条目沿用电脑端名称，导出入口只保留手机可用的 3D 成品与动画：

| 分组 | 内容 |
| --- | --- |
| 模拟 | 播放 / 暂停、单步、重置模拟 |
| 模拟步长 | `1/30 s` / `1/60 s` / `1/120 s` / `1/240 s` |
| 选择与编辑 | 撤销、重做（条目下写出将要撤销的动作名）、全选版片、取消选择、删除选中 |
| 版片显示 | 显示全部版片、隐藏未选版片、隐藏选中版片 |
| 模特与场景 | 模特模型…、参考物体…、环境贴图…、恢复内置环境、清除全部参考物体 |
| 工程 | 新建工程、打开…、保存、另存为…、立即保存快照、从快照恢复（恢复到最新一份） |
| 自动保存 | 关闭、每 30 秒、每 1 分钟（默认）、每 5 分钟 |
| 最近打开 | 最近 5 条本地存档，带保存时间 |
| 导出 | 服装 GLB…、服装 OBJ…、截图 PNG、动画 WebM… |
| 帮助 | 快捷键总览…、关于 OpenCloth |

> **说明**：接上蓝牙键盘时，全局与 3D 视口两类快捷键在手机上有效；布局与 2D 制版相关的快捷键在手机上没有对应视图，不会触发。

## 6. 手机上没有的功能

- 2D 制版视口：选点、拖片、加点、微调都不在手机上做。
- 模板库：不能换模板或改模板参数（衣长、胸围一类尺寸）。
- 场景树与时间轴：对象树与模拟时长读数只在电脑端出现，手机顶栏只留状态与读数。
- 分屏与窗格焦点：手机只有一个视口，【视图】里的四种布局不出现在菜单中。
- 【打PIN】【拔PIN】【清除PIN】与【重建网格】：留在电脑端的 3D 工具条上。
- 应变热图：渲染标签的应变热图与应变报告 CSV 只在电脑端出现，手机【显示】抽屉只带合身热图。
- 复制粘贴版片、左右均分：只在电脑端有意义。

改版型请回到电脑端，用【保存】导出的 `.ocproj.json` 接着做。

## 7. 常见问题

- **画面卡顿**：先【暂停】模拟；显示模式若在【光线追踪】，布料每帧变形都会重置渐进采样，静止后才会收敛出无噪点画面。顶栏的 `SPP 0/N` 后面会写明当前受哪一项限制：【布料每帧在变】、【视角未静止】、【光追内核加载中】、【光栅过渡中】、【本机不支持】。
- **切到光线追踪却一直是光栅画面、也不报错**：首次切换会实际运行一次最小光追来判定这台设备；判定不通过会弹【本机 WebGPU 跑不了光线追踪（…）】并把选项置灰，判定通过后顶栏会出现非 0 的采样读数；仍停在 `SPP 0` 时，后面的状态码说明限制来自相机未静止还是布料仍在变形。平板走的是电脑界面，把地址后加 `?ui=mobile` 能让读数落在顶栏上，更好读。
- **抽屉里的数字无法输入**：属性行里的数值格在手机上单击即进入输入态，用屏幕键盘改值后点回车或别处确认。
- **想要手机界面但没自动切换**：地址后加 `?ui=mobile`；想恢复电脑界面加 `?ui=desktop` 或直接去掉参数。
- **导出的文件找不到**：Android 在浏览器下载目录；iOS 会先在新标签里打开，用分享 → 存储到【文件】。
