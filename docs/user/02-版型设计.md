# 版型设计

版型（Pattern）是服装的 2D 展开图，也是全流程的起点。这篇介绍：

- 2D 制版工作台：视图操作与工具条（§1、§3）。
- 版型的来源：模板库、编辑操作与属性（§2、§4、§5）。
- 影响模拟精度的布料密度（§6）。

## 1. 制版视图

**3D 左 + 2D 右 分屏**是默认布局，右侧窗格即版型工作台，工具在它上方的工具条里；想专注制版可按 `2` 切到全屏 2D（四种布局与快捷键见 [01-快速上手](./01-快速上手.md) §2.3）。

| 操作 | 方法 |
| --- | --- |
| 缩放 | 滚轮，以光标位置为锚点（0.5× ~ 50×） |
| 平移 | 按住中键、按住 `空格` 拖动，或选「平移画布」工具 |
| 适应视图 | `F` 或工具条「适应视图」（双击空白处同样适应视图），收放到全部版型片的范围 |
| 单位 | 画布尺寸以厘米计，网格随缩放显示 5 / 10 / 20 cm |
| 吸附 | 拖动默认按 0.5 cm 网格吸附，按住 `Alt` 自由移动 |

2D 视图与 3D 相机的取景彼此独立：移动 3D 不会改变 2D 的缩放，反之亦然。

## 2. 版型的来源：模板库

版型片**来自左侧模板库**。五张卡片，点开可调尺寸，再生成：

- **应用**：用模板替换当前版型。
- **追加**：保留已有版型片，把模板的版型片排在右侧（例如给裙子补一对袖子）。

两者都进撤销历史，`Ctrl+Z` 可以退回。新片沿用工程里的第一条面料；工程里还没有面料时会自动建一份「棉」。

| 模板 | 版型片 | 可调参数（cm，除片数外） |
| --- | --- | --- |
| T 恤 | 前片 + 后片 + 左袖 + 右袖 | 胸围 96（76–140）、衣长 68（50–85）、袖长 20（8–62）、肩宽 42（32–56）、领宽 18（14–26）、领深 8（4–14） |
| 衬衫 | 前片 + 后片 + 左袖 + 右袖 + 前领片 + 后领片 | 胸围 100（76–140）、衣长 72（55–90）、袖长 55（20–62）、袖山 16（8–20）、肩宽 44（32–56）、领宽 17（14–24）、领深 9（5–14）、领座高 4（2–9） |
| 裙子 | 前裙片 N + 后裙片 N（A 字摆，片数取偶数） | 腰围 72（56–120）、裙长 55（30–120）、摆围 132（60–320）、片数 6（2–12 片） |
| 连衣裙 | 前上身片 + 后上身片 + 前裙片 + 后裙片 | 胸围 92（76–130）、腰围 76（56–120）、摆围 160（80–320）、腰节 36（28–46）、衣长 112（70–145）、肩宽 40（30–54）、领宽 18（14–24）、领深 10（6–16） |
| 袖子 | 左袖 + 右袖 | 袖长 55（15–65）、袖山高 16（6–22）、上臂围 32（22–48）、袖口围 24（16–36） |

- 数值直接键入即可，超出范围会自动收到边界上。
- 模板会按当前人体的尺寸（身高、胸围、腰围、臀围）把每张版型片包裹到相应部位作为初始位置：环绕的锚点高度与半径都取自人体测量点，所以改完三围，已生成版片的摆放会随新体型变化，随后由模拟自然垂坠。

## 3. 制版工具条

三个工具真正响应画布：

| 工具 | 作用 |
| --- | --- |
| 选择 | 单击选中版型片；`Ctrl`/`Shift` + 单击加选或减选；空白处拖动框选；空白处单击取消选择。选中后可整片拖动，也可拖动轮廓上的顶点 |
| 线上加点 | 在**已选中**版型片的轮廓边附近单击，向那条边插入一个顶点，用于辅助定位与细分轮廓 |
| 平移画布 | 左键拖动移动视图（等效于中键或按住 `空格`） |

> **注**：**直线、曲线、内部线、省道** 四个按钮当前没有接入绘制，选中它们画布不会响应；**缝合** 按钮只切换缝线连接的显示（[03-缝合与着装](./03-缝合与着装.md) §1）。现阶段的工作方式是：用模板生成版型，再用选择与线上加点做调整和定位。

## 4. 编辑操作

| 操作 | 方法 |
| --- | --- |
| 移动整片 / 顶点 | 选择工具下拖动（0.5 cm 吸附，`Alt` 自由移动） |
| 微调 | `方向键` 每次 0.5 cm，`Shift+方向键` 每次 1 cm；一段连续微调算一步撤销 |
| 删除 | 选中后按 `Delete` / `Backspace`，或 编辑 → 删除选中 |
| 复制 / 粘贴 | `Ctrl+C` 复制选中版片，`Ctrl+V` 在其右侧生成完整副本。副本重命名成「X 副本」，带着原片之间的缝合关系，之后与原片各自独立——移动、删除、换材质互不影响 |
| 临时隐藏 | 视图 → 显示全部版片 / 隐藏未选版片 / 隐藏选中版片，或场景树行首的眼睛图标。隐藏只是不再绘制，模拟与缝合照常；隐藏中的版片在 2D 里不可再被选中 |
| 缝份量 | 对象标签「模拟」区块的滑条（见下） |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z`（菜单里写出具体操作名），最多回退 100 步 |

### 缝份量

真实缝纫需要在轮廓外预留缝份。选中版型片后，用对象标签「模拟」区块的「缝份量」调整：0–2 cm，步长 0.05，默认 1 cm，松手生效。

- 系统沿轮廓向外偏移生成缝边，**缝份参与模拟网格**（不是一条独立的显示线）。
- 缝合时两条边按同一条缝边线对齐。
- 凹角密集或内偏移导致自交时会自动退化为更保守的逐点偏移，角部尺寸会略小。

> **注**：缝份量改动会重建布料并重置模拟；缝型与线色的调整在 [03-缝合与着装](./03-缝合与着装.md) §2。

## 5. 版型片的属性

选中场景树里的一张版型片，对象标签从上到下是：

- **对象**：名称（回车或点别处生效）、可见性勾选、类型。
- **变换**：位置（m）、旋转（°）、缩放三轴拖拽单元，加「复位变换」。版型片的变换在松手后**重建布料并重置模拟**。
- **版型**（只读）：轮廓的宽 × 高、轮廓边数量、省道数、内部线数——用来确认这片版型的规模与结构。
- **模拟**：缝份量、网格边长（0.5–4 cm；密度实际取全局值，见 §6）。
- **着装**：这张片的着装方式，模板生成的片写作「环绕 躯干 / 手臂 / 领口」，未指定 drape 的片显示「自动推断」——按片名判断（名字里含「袖」的走手臂，含「后」的走后半圈）。

## 6. 布料密度

- 模拟精度由场景标签的「全局网格边长」决定（0.8–3 cm，默认 1.5）。
- 数值越大，布料网格越疏、计算越快、褶皱越粗；越小越细腻但越慢。
- 松手后重建全部布料，模拟回到初始状态（未着装）。

> **说明**：对象标签里每张片也有一个「网格边长」滑条（0.5–4 cm），当前它不参与模拟计算，密度一律取全局值。

一件服装的布料网格点控制在 5000~10000 之间能获得流畅的实时体验，最常用的手段就是把全局网格边长调大。

## 7. 当前不支持

- 省道：既不显示也不闭合，数值（省量）没有生效路径，界面上的「省道」计数只反映模板与复制留下的占位数据。
- 内部线：不绘制、不影响模拟。
- 曲线控制柄的拖动编辑：只能在已生成的边上加点，不能拖动控制柄改形状。
- 带镂空洞的裁片。

## 8. 下一步

版型确定后，模板已经把片与片之间的缝合关系一并生成，可以直接着装与模拟，请阅读 [03-缝合与着装](./03-缝合与着装.md)。
