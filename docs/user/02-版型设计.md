# 版型设计

版型（Pattern）是服装的 2D 展开图，也是全流程的起点。章节顺序依次为：2D 制版视图与工具条（§1、§3）、版型的来源（§2、§4）、选择与编辑、内部线与省道、生产标记、放码（§5–§8）、版片属性与布料密度（§9、§10）、当前不支持的编辑方式（§11）、下一步（§12）。

## 1. 制版视图

**3D 左 + 2D 右 分屏**是默认布局，右侧窗格即版型工作台，工具在它上方的工具条里；想专注制版可按 `2` 切到全屏 2D（四种布局与快捷键见 [01-快速上手](./01-快速上手.md) §2.3）。

### 1.1 鼠标与键盘操作

| 操作 | 方法 |
| --- | --- |
| 缩放 | 滚轮，以光标位置为锚点（0.5× ~ 50×） |
| 平移 | 按住中键拖拽，或按住 `空格` 用左键拖动 |
| 适应视图 | `F`、工具条右端的「适应」按钮或双击空白处，收放到全部可见版片的范围 |
| 单位 | 画布尺寸以厘米计；网格随缩放自动变档（5 / 10 / 20 cm），顶部与左边常驻标尺 |
| 吸附 | 绘图工具（直线、曲线、矩形、圆、椭圆、内部线）的落点先吸附到最近的顶点、边中点、切点或等距点，否则吸附 0.5 cm 网格；拖动版片与顶点按 0.5 cm 网格吸附；按住 `Alt` 一律自由 |
| 精确输入 | 右键弹出 `输入位移 dx,dy（cm）`，把选中的版片或点按给定位移精确移动；直线绘制途中右键改为弹出 `输入长度与角度（cm，°）`，按数值补一个点 |

### 1.2 画布提示与取景

画布左下角常驻一行操作提示（如「2D 制版 · 缩放 4.0x · 单击选片/Ctrl加选/空白拖框选 · 拖点或拖动版片（0.5cm吸附，Alt自由）…」），内容随当前工具与布局变化；分屏布局下提示会精简；空格平移与方向键微调只作用于聚焦的 2D 窗格，`F` 只要不是「仅 3D」布局即可用。

顶部与左边的标尺、随缩放变档的网格是固定显示：标尺是两条 18 px 的刻度带，刻度按缩放自动选步长（0.1 cm 起，保证主刻度至少隔 64 px），数字就是版型坐标的厘米值；网格在放得近时用 5 cm 间距，稍远 10 cm、更远 20 cm，间距过密时自动加倍，避免网格线过密而难以分辨。

2D 视图与 3D 相机的取景彼此独立：移动 3D 不会改变 2D 的缩放，反之亦然。

## 2. 版型的来源

### 2.1 从模板库导入

版片最常**来自左侧模板库**。五张卡片，点开可调尺寸，再生成。

**替换版型**用模板替换当前版型（会清空已有版片）；**追加版型**保留已有版片，把模板的版片排在右侧（例如给裙子补一对袖子）。两者都进撤销历史，`Ctrl+Z` 可以退回。新片沿用工程里的第一条面料；工程里还没有面料时会自动建一份「棉」。

| 模板 | 版片 | 可调参数（cm，除片数外） |
| --- | --- | --- |
| T 恤 | 前片 + 后片 + 左袖 + 右袖 | 胸围 96（76–140）、衣长 68（50–85）、袖长 20（8–62）、肩宽 42（32–56）、领宽 18（14–26）、领深 8（4–14） |
| 衬衫 | 前片 + 后片 + 左袖 + 右袖 + 前领片 + 后领片 | 胸围 100（76–140）、衣长 72（55–90）、袖长 55（20–62）、袖山 16（8–20）、肩宽 44（32–56）、领宽 17（14–24）、领深 9（5–14）、领座高 4（2–9） |
| 裙子 | 前裙片 N + 后裙片 N（A 字摆，片数取偶数） | 腰围 72（56–120）、裙长 55（30–120）、摆围 132（60–320）、片数 6（2–12 片） |
| 连衣裙 | 前上身片 + 后上身片 + 前裙片 + 后裙片 | 胸围 92（76–130）、腰围 76（56–120）、摆围 160（80–320）、腰节 36（28–46）、衣长 112（70–145）、肩宽 40（30–54）、领宽 18（14–24）、领深 10（6–16） |
| 袖子 | 左袖 + 右袖 | 袖长 55（15–65）、袖山高 16（6–22）、上臂围 32（22–48）、袖口围 24（16–36） |

数值直接键入即可，超出范围会自动收到边界上。模板会按当前模特的尺寸（身高、胸围、腰围、臀围）把每张版片贴合到相应部位作为初始位置：环绕的锚点高度与半径都取自模特测量点，所以改完三围，已生成版片的摆放会随新体型变化，随后由模拟自然垂坠。

### 2.2 从文件导入

文件 → 导入 → **DXF 版型…** 或 **JSON 版型…** 可以带入外部版型；导入以一步可撤销的操作替换当前版型（格式要求与失败提示见 [06-导出与工程](./06-导出与工程.md) §2）。§4 的绘图工具则能完全从零起片。

## 3. 制版工具条

工具条从左到右是：
- 左侧的工具按钮
- 中间四个菜单 **结构 / 标记 / 检查 / 智能**
- 右侧的 **框选 / 图层 / 适应** 按钮

### 3.1 工具按钮

每个按钮的悬停提示写出了它的操作方式：

| 工具 | 悬停提示 | 作用 |
| --- | --- | --- |
| 选择 | 选择 (点击/Ctrl加选) | 见 §5 的选择与拖动 |
| 线上加点 | 线上加点 | 在**已选中**版片的轮廓边附近单击，向那条边插入一个顶点；未选中任何片时对最近的边生效 |
| 直线 / 曲线 | 直线 (Enter闭合/Esc取消/Backspace退点) / 曲线 (Ctrl+单击插入曲线点)（箭头切换工具） | 同一个按钮里放两种画线方式，图标显示当前那一种。直线：单击逐点画折线，`Enter` 或双击闭合成片（至少 3 个点），`Backspace` 退掉上一个点，`Esc` 取消整笔，按住 `Shift` 落点约束到 45° 的整数倍方向；曲线：普通单击放角点，`Ctrl`+单击放曲线点（带两侧手柄），其余同直线 |
| 矩形 / 圆 / 椭圆 | 矩形 / 圆 / 椭圆（箭头切换工具） | 同一个按钮里放三种画片方式，图标显示当前那一种。矩形拖出矩形片（按住 `Shift` 画正方形），圆从圆心拖出半径画圆片，椭圆拖出外接框画椭圆片 |
| 内部线 | 内部线 | 在版片内单击画折线，`Enter` 结束成一条内部线（§6） |
| 省道 | 省道 | 依次单击两条相邻的轮廓边、再单击省尖位置，落一个省道（§6） |
| 缝合 | 缝合 | 进入缝合工作态：2D 里画出缝纫线连接，并可沿边拖选区间手工创建缝合（[03-缝合与着装](./03-缝合与着装.md) §1） |
| 明线 | 明线 (单击轮廓边) | 在轮廓边上单击，落下一条沿边向内偏移的装饰线，默认偏移 3 mm、单行、针距 3 mm／空距 2 mm（§7.3） |
| 辅料 | 辅料：纽扣 (点击版片放置，箭头换类型) | 在版片上单击，落下当前类型的标记；按钮自带的箭头展开类型表（纽扣 / 气眼 / 铆钉 / 按扣），选中即换类型并切到这个工具（§3.3） |

### 3.2 结构菜单

| 条目 | 做什么 |
| --- | --- |
| 轮廓分割（画切割线后回车） | 启用分割工具：在片上画一条切割折线，`Enter` 把版片沿它切成两片 |
| 开内孔（画闭合环后回车） | 启用内孔工具：画一个闭合环，`Enter` 在片内挖洞；洞参与模拟网格与导出 |
| 沿纵向镜像复制 | 选中一个版片，生成「X 镜像」副本并记录对称关系；之后编辑任一侧，另一侧自动跟随 |
| 沿横向镜像复制 | 同上，镜像轴换成横向 |
| 沿选中边镜像复制 | 需选中一个版片和一条边，以那条边为轴出镜像片 |
| 同步镜像片 | 手动让镜像片按对称轴重新生成一次；正常情况下不需要，编辑后会自动同步 |
| 合并选中的两片 | 选中两个版片，按轮廓求并集合成一片；两片不相交时不会生效 |
| 由选中边成片 | 至少选中三条首尾相接的边，用它们围出一个新版片 |
| 多段缝合（首条边分段对多片边） | 选中一条基准边加至少两条目标边，把基准边等分成段后逐段缝合 |
| 选中角点倒圆角 | 选中一个或多个角点，弹出 `圆角半径 (cm)`（默认 1.5），把角切成圆弧；挂在这个角两条边上的缝合区间按比例挪到剩下的边上 |
| 断开选中顶点 | 选中一个顶点，让经过它的轮廓不再共用这个点：夹在中间的一处收拢会把片分成两片，跨片共用的点则拆回两份独立几何 |
| 连接选中两个端点 | 选中两个自由端点，把它们并成一个共享顶点并闭合出轮廓；端点不自由或连上后自交会失败 |
| 合并选中共线边 | 选中两条以上首尾相接的同一直线边，压成一条边，挂在被合并边上的缝合区间按比例搬到新边 |
| 简化选中曲线 | 选中曲线边，弹出 `拟合容差 (cm)`（默认 0.05），按最小二乘重拟控制点，容差内的偏差被消除 |
| 沿选中边生成等距内部线 | 选中一条边，弹出 `等距距离 (cm)，可多个`（默认 `1, 2`），在该边内侧生成若干条平行内部线 |
| 闭合内部线独立成片 | 选中一条闭合内部线，把它围出的区域搬成一张新版片，并与原片之间自动建立缝合 |
| 在选中边上开菱形省 | 选中一条轮廓边，弹出 `省量与省长 (cm)`（默认 `2, 8`），在边中点处生成一枚朝片内的菱形省 |
| 接角圆顺：选中缝合的起点 | 选中一条缝合，弹出 `圆顺半径 (cm)`（默认 1.5），给缝口起点处两片各自的角倒一段相切圆弧（[03-缝合与着装](./03-缝合与着装.md) §2.3） |
| 接角圆顺：选中缝合的终点 | 同上，处理缝口的另一端 |

> **注**：结构操作都有前置选择要求（如镜像要求恰好选中一个版片、倒圆角要求选中角点）；不满足或几何不合法时该操作不生效，视口下方会短暂弹出失败原因（如「请先选中一个要镜像的版片」）。执行前先按提示核对选中的对象。

### 3.3 标记菜单

三个生产标记工具（当前选中的带 ✓），落下的标记在 2D 里绘制、随 DXF / SVG 导出（§7）：

| 条目 | 操作 |
| --- | --- |
| 刀口：单击轮廓边 | 在轮廓边上单击落一个对位刀口 |
| 文字注释：单击版片 | 在版片内单击落一条注释，默认文字「标注」，选中后在对象标签改文字、角度、字号 |
| 尺寸线：单击两个点 | 依次单击两个顶点，生成两点距离标注，数值随几何实时变化 |

工具条上的「**辅料**」按钮自带一个下拉箭头，点开列出四种类型（纽扣 / 气眼 / 铆钉 / 按扣，默认纽扣）：选中一种就把当前工具切到「辅料」，下一次在版片上单击即按这个类型落下。类型只影响新落的标记，已有标记在对象标签里改（§7.4）。

### 3.4 检查菜单

「检查」（悬停提示「检查轮廓、缝合、省道与放码」）打开时重新运行三组校验：轮廓闭合、缝合区间、省道引用等拓扑问题，缝合本身的提示（两侧被缝段长度差过大、同一对边被重复配对，行首带「**警告：**」），以及各码放码后的边长递增与轮廓自相交问题。结果逐行列出；**点一行会直接选中出问题的那个对象**，属性面板随即可以改它。没有问题时列出「未发现问题」。

> **注**：警告只作提示，不阻止操作——缩缝、收省这类故意有长度差的缝合不会报，其余情况下缝合照旧能保存（[03-缝合与着装](./03-缝合与着装.md) §2）。

### 3.5 智能菜单

「智能」（悬停提示「按布纹区域排位，并给出缝合建议」）菜单先给出**自动排位**：按着装区域（躯干 / 领口 / 手臂 / 腿）把版片分行排好，片间距 4 cm，一步撤销（§5.4）。

菜单下方直接列出**自动缝合建议**：算法按语义、长度、方向与曲率给出缝口配对，每行写着推荐理由与评分（如「语义匹配 shoulder/shoulder，长度比 1.00，方向一致，曲率相近 · 0.87」）。点一行创建这条缝合（一步撤销）；多于一行时出现「全部接受（N 条）」，一次接受全部建议。已有缝口的边会被跳过，没有配对时列出「没有可匹配的缝合建议」（[03-缝合与着装](./03-缝合与着装.md) §1）。

### 3.6 框选与图层

工具条右端有两个下拉按钮，都只影响绘制与选择，不动数据、不进撤销历史。

#### 3.6.1 框选

**框选**：勾选在空白处拖出选框时收集哪些类型——`版片`、`顶点`、`轮廓边`、`内部线`、`省道`、`缝合`、`刀口`、`注释`、`尺寸线`、`印花`、`明线`、`辅料`。默认只有 `版片`，即框到谁的轮廓角点就选中谁；勾上其它类型后，一次框选可以同时选出范围内的边、刀口、印花等。这个勾选表只在本次会话有效。

#### 3.6.2 图层

**图层**：逐层开关。默认开：内部线、省道、刀口、布纹线、注释、尺寸线、印花、明线、辅料；默认关：缝份线、齐码套叠、拼接预览。

- 内部线 / 省道 / 刀口 / 布纹线 / 注释 / 尺寸线：各自的绘制图层。
- **印花 / 明线 / 辅料**：三类生产物件的图层。关掉只是 2D 不画，数据、3D 印花贴图与导出清单照常。
- **缝份线**：这一层就是**净边／毛边切换**。关掉只看见净边（缝纫线）；打开时额外画出橙色虚线的切割轮廓（毛边），它是逐边缝份量与角型（尖角 / 圆弧 / 斜角）算出来的同一条轮廓，与导出 DXF / SVG / PDF 的毛边完全一致。
- **齐码套叠**：在所有可见版片背后叠画其它尺码的轮廓线（当前编辑码除外），放码时的对照视图；开着时方向键改为编辑点的放缩量（§5.2、§8）。
- **拼接预览**：把选中的缝合按「缝好压平」的样子画出另一片，并标出缝口两端的接角角度（[03-缝合与着装](./03-缝合与着装.md) §2.3）。

## 4. 从零画一片

典型流程：

1. 选「矩形」拖一个框，或选「直线」沿设计线单击、`Enter` 闭合。
2. 曲线边缘用「曲线」工具（`Ctrl`+单击出带手柄的曲线点）。
3. 随后在选择工具下**拖动端点的手柄**即可改弧度——拖动曲线点的一个手柄时，另一个手柄会对称跟随（曲线点），角点则没有手柄。
4. 由已有边围新片用 结构 ▸ 由选中边成片。

## 5. 选择与编辑操作

### 5.1 选择

| 想选什么 | 方法 |
| --- | --- |
| 版片 | 选择工具下单击；`Ctrl`/`Shift`+单击加选或减选；在空白处拖出选框（轮廓角点进入选框即选中，能框到哪些类型由「框选」下拉决定，§3.6）；空白处单击或按 `Esc` 取消全部 |
| 顶点 / 边 / 刀口 / 注释 | 选择工具下直接单击画布上的点、轮廓边或标记，右侧对象标签同步显示它的属性 |
| 内部线 / 省道 / 缝合 / 尺寸线 | 同样可以单击选中——命中的是离光标最近的一条，排在轮廓边之后、版片实体之前，所以片内部的这些标记点得中而不会误选整片 |
| 印花 / 明线 / 辅料 | 也可以单击选中；三类生产物件排在轮廓边之前被命中，辅料符号最小所以最先，印花其次，明线最后 |
| 全部版片 | 编辑 → 全选版片 |

选中场景树里版片行下展开的 **边 / 点 / 内部线 / 省道 / 刀口 / 注释 / 尺寸线** 子行，效果与在 2D 里单击一致；每片的镂空轮廓单独成一行「镂空 N」，展开可选其中的边。2D 画布上同样可以直接点选这些对象。

**印花 / 明线 / 辅料** 不在版片下面，而是各自成一级集合，与「服装」「缝纫线」并列：每行行尾注记所属版片，点行选中对象，行首眼睛控制这一个对象的显隐，集合行的眼睛一次开关全部。「印花」集合行还带一个 `＋`，以当前选中版片的轮廓中心为落点，弹出图片选择后直接添加（§7.2）。

场景树里**点击则选中该对象**（版片行同样如此，行首的箭头或双击才展开 / 收起子项）。轮廓、内部线、省道与刀口等只在 2D 画布上绘制，3D 视口不为它们额外生成几何体；印花在 3D 里合成进面料底色，明线在 3D 里叠画成跟随布料的线，辅料只有 2D 符号。选中版片时 3D 里仍以半透明淡黄色覆盖整片。

### 5.2 移动与微调

| 操作 | 方法 |
| --- | --- |
| 移动整片 / 顶点 | 选择工具下拖动（0.5 cm 吸附，`Alt` 自由移动）；拖一个顶点会带走挂在它身上的边 |
| 微调 | `方向键` 每次 0.5 cm，`Shift+方向键` 每次 1 cm；一段连续微调算一步撤销 |
| 精确位移 | 右键输入 `输入位移 dx,dy（cm）` |
| 拖动印花 / 辅料 | 选择工具下直接拖动，0.5 cm 吸附，`Alt` 自由；松手记一步撤销，锁定的片拖不动 |
| 缩放印花 | 选中印花后拖它虚线框的四个角点：中心不动，宽高各自跟着光标走（最小 0.1 cm），松手记一步撤销 |
| 旋转印花 | 2D 窗格聚焦时按 `R` 逆时针转 15°，`Shift+R` 顺时针；多选的印花一起转，一次记一步撤销。也可以拖对象标签的「角度」滑杆 |
| 删除 | 选中版片或元素后按 `Delete` / `Backspace`，或 编辑 → 删除选中。删除版片会一并删掉它的印花、明线、辅料（撤销可整体恢复） |
| 复制 / 粘贴 | `Ctrl+C` 复制选中版片，`Ctrl+V` 在其右侧生成完整副本。副本重命名成「X 副本」，带着原片之间的缝合关系，之后与原片各自独立——移动、删除、换材质互不影响 |
| 临时隐藏 | 场景树行首的眼睛图标（整组可点集合行一起切）。隐藏只是不再绘制，模拟与缝合照常；隐藏中的版片在 2D 里不可再被选中 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z`（菜单里写出具体操作名），最多回退 100 步 |

> **注**：**齐码套叠**打开且恰好选中**一个点**时，方向键不再移动几何，而是将那个点**当前码的放缩量**按同一步长增减（§8）。

### 5.3 改轮廓：分割、圆角、内孔、镜像、合并

见 §3.2 结构菜单。这些操作都进撤销历史；锁定（对象标签「对象」块的「锁定」）的版片不能被拖动。

通过镜像建立对称关系后，编辑任意一侧的轮廓会自动重建另一侧：改点、改边、改弧或整片缩放都算，一次操作仍只有一条撤销记录，撤销时两侧一起回到旧几何。两侧在同一条命令里都改变时，以编号较小的一侧为源。删除对称关系（例如删掉带对称关系的片）后不再联动。

编辑圆弧边时，「边」区块还会出现**半径**与**圆心角**两个数值格：改半径时两端点不动，圆心自动落在保持原弧方向的一侧；半径小于弦长一半会被夹到弦长一半（半圆）。改圆心角时半径随之求出，顺时针／逆时针方向保持不变。两格都按回车或失焦提交，各算一步撤销。

### 5.4 自动排位

结构之外，工具条「智能 ▸ 自动排位」按片名推断的着装区域把全部分片重新分行摆放，适合导入 DXF 或追加模板后整理桌面。

## 6. 内部线与省道

### 6.1 内部线

**内部线**（工具条「内部线」）：在片内画折线，`Enter` 生成。选中后对象标签可改**用途**：分割线 / 折痕 / 装饰线，三种用途在 2D 以不同线型区分绘制。

### 6.2 省道

**省道**（工具条「省道」）：先单击第一条轮廓边、再单击**与它相邻**的另一条边（两腿不相邻会失败），第三下决定省尖位置，默认省量 2 cm。对象标签的「省道」区块可调**省量**（0.5–6 cm）、查看**省尖**坐标，还有**转移到选中边**按钮——先选中一条轮廓边再点它，省的两腿会搬到那条边的中点处。

### 6.3 显示与模拟效果

省道与内部线在 2D、SVG 与 DXF 里都按图层画出，并可被「图层」下拉隐藏。

> **注**：省道可以真的缝上——选中省道后在对象标签勾「收省（模拟时缝合省边）」，求解器把两条省边逐点缝合，布料向省尖收拢，取消勾选即放开。内部线用途选「折痕」时，那片布料沿折线得到额外刚度，软硬由材质物理里的「折痕刚度」调（0–1，默认 0.85），两者都只重排约束，不重建布料、不重置模拟。

## 7. 生产标记

| 标记 | 画上去 | 选中后可调 |
| --- | --- | --- |
| 刀口 | 标记 ▸ 刀口，单击轮廓边 | 所在边、位置（沿边百分比）、宽度（1–10 mm）、样式（V 形 / T 形 / 钻孔）、删除刀口；**位置也能直接拖**：选择工具下按住 2D 里的刀口沿所属边（含镂空环）拖动，松手记一步撤销，锁定的片拖不动 |
| 文字注释 | 标记 ▸ 文字注释，单击版片 | 文字、角度（-180–180°）、字号（2–12 mm）、坐标只读、删除注释 |
| 尺寸线 | 标记 ▸ 尺寸线，单击两个点 | 尺寸线类型（两点距离 / 边长 / 角度）、数值实时量出、各码数值对照表、删除标注 |
| 印花 | 场景树「印花」集合行的 `＋`（先选中版片） | 图片、宽 × 高、角度、不透明度、平铺次数、位置、删除印花（§7.2） |
| 明线 | 工具条「明线」，单击轮廓边 | 起点 / 终点、偏移、行数、行距、线色、针距 / 空距、删除明线（§7.3） |
| 辅料 | 工具条「辅料」，单击版片 | 类型、直径、颜色、数量、单价、位置、删除辅料（§7.4） |

### 7.1 刀口、注释与尺寸线

上表前三行的字段都写在对象标签里，刀口的位置还能在 2D 直接拖动。

### 7.2 印花

- **落点**：先在场景树选中一张版片，点「印花」集合行的 `＋`，浏览器弹出图片选择；图片上限 8 MB，会先转成 PNG 再存进工程。新印花默认 12 × 12 cm，中心落在该片轮廓中心，之后拖动或改位置移到想要的地方。
- **换图**：在 2D 里双击已有印花，弹出图片选择，只替换图案，摆放参数不变。
- **2D**：图片按摆放裁进印花矩形并平铺；所属版片的外接框另用灰色虚线画出，方便对照图案有没有超出片外。选中后四个角点出现手柄。拖动、拖角点缩放、`R` 旋转都在 §5.2。
- **3D**：按版片 UV 把图案裁切合成进面料底色贴图，随布料模拟一起变形；改位置、大小、角度、平铺或不透明度都会重绘，不用重启模拟。
- **对象标签**：版片、图片文件名、宽 × 高（0.1–1000 cm）、角度（-180–180°）、不透明度（0–1）、平铺（横向 × 纵向，各 1–50 次）、位置（相对版片轮廓外接框中心的 X / Y 偏移，cm）。名称在场景树里改。

### 7.3 明线

- **落点**：选「明线」工具后单击轮廓边，默认偏移 3 mm（向版片内侧）、单行、行距 4 mm、线色 `#d9a441`、针距 3 mm、空距 2 mm。
- **2D**：按针距与空距画虚线，多行时逐行向片内递加行距；被缝区间外的边不画。
- **3D**：每行的采样点吸附到该片布料网格的顶点，随模拟每帧更新线段位置，所以线贴着曲面而不悬空。
- **对象标签**：起点 / 终点（沿线 0–1）、偏移（0–20 mm）、行数（1–5）、行距（0.5–20 mm）、线色、针距与空距（0.5–20 mm）。物料清单里的长度按「区间长度 × 行数」换算成米（[06-导出与工程](./06-导出与工程.md) §3.5）。
- 明线只能挂在所属版片的轮廓边上；删除那条边或那片版片时一并删除。

### 7.4 辅料

- **落点**：先用工具条「辅料」按钮的箭头下拉选种类，再在版片上单击。默认直径 12 mm、颜色 `#b08d57`、数量 1。
- **2D 符号**：纽扣与按扣画实心圆，气眼画空心圆，铆钉画实心小方块；符号随直径缩放，最小按 4 mm 画。
- **对象标签**：版片、类型（纽扣 / 气眼 / 铆钉 / 按扣）、直径（0.5–200 mm）、颜色、数量（1–9999，这个标记代表的件数）、单价（元，填 0 表示不计价）、位置（绝对制版坐标 X / Y，cm）。
- 辅料只出现在 2D 与物料清单，3D 不生成实体；数量计入物料清单的「个」，填了单价才计算金额（[06-导出与工程](./06-导出与工程.md) §3.6）。

### 7.5 布纹线

**布纹线**每片自带，不通过标记工具落点。对象标签「生产」区块用三行调整：**布纹线角度**（-180–180°）、**布纹线位置**（相对该片轮廓包围盒中心的 X / Y 偏移，cm，填 0 回正中）、**布纹线长度**（cm，填 0 按短边 60% 自动）。它随片绘制，导出 DXF / SVG / PDF 与排料都读同一份位置与长度。

## 8. 放码

尺码表是工程级设置，打开属性编辑器的**工程**标签即可看到底部「**尺码**」区块——入口。

### 8.1 尺码表

- **添加尺码**：按 A、B、C… 追加码号，第一个码自动成为**基码**。
- 每行的码名可直接改名（回车或点别处生效），行上有 **↑ / ↓** 调序、「设基码」「用此码」「删除」按钮，基码与当前码在行上标注。
- **顺序即档差方向**：↑↓ 只改尺码表里的排列次序，不动几何；齐码套叠、各码数值表和放码检查都按新顺序解释。

### 8.2 切码与试穿

**用此码**把版型几何按放缩量整体重解为那一码（曲线手柄随两端点平均移动，圆弧随两端重解），并重启模拟——试穿其它码就按它。

### 8.3 点放码

选中一个点，对象标签「点」区块可编辑 X/Y 坐标、切换**点类型**（角点 / 曲线点），并为每个非基码列一行「放码 码名」的两个数值格（该码相对基码的 X/Y 放缩量，cm）+ **复制** / **粘贴** 按钮。

- 直接在框里输入，或打开 图层 ▸ 齐码套叠 后用方向键微调（§5.2）。
- **复制**取当前行这一码的 X/Y 放缩量，**粘贴**把它一次写给所有选中的点（没选中点时只写回当前行那个点），一次粘贴是一条撤销记录。
- 剪贴板只在本次会话里有效。

### 8.4 套叠与检查

**齐码套叠**在 2D 里叠画所有其它码的轮廓，所见即放码结果。**检查**由工具条「检查」逐边验证「边长随码递增」，并验证每个码下轮廓不自相交，点问题行跳到出错对象。

## 9. 版片的属性

选中场景树里的一张版片，右侧属性编辑器分六个标签：**对象 / 材质 / 模拟器 / 生成器 / 渲染 / 工程**。版片相关的四页按下面的区块顺序排列；选中任何对象时，「对象」标签最顶上的「对象」块都给出同样的三项——**名称**可改、**类型**、**可见性 / 启用**；没有显隐状态的对象只给出前两项。

### 9.1 对象：身份、锁定与变换

**对象**块给出名称（回车或点别处生效）、可见性勾选、版片特有的**锁定**（锁定后不能被拖动与移动命令命中）与**分组**，最后是类型。**变换**块给出位置（m）、旋转（°）与缩放三轴拖拽单元，另有「复位变换」；版片的变换在松手后**重建布料并重置模拟**。

### 9.2 对象：版型、尺寸与生产

**版型**块：给出轮廓边数、省道数、内部线数三项只读读数，以及可调的**缝份量（本片默认）**（0–2 cm，步长 0.05，默认 1，松手生效；改动会重建布料并重置模拟）。最后两行是**对称**（镜像产生的片写出对称轴）与**镂空**（内孔数量）两项只读结构信息。

**尺寸**块：先给出轮廓的宽 × 高（按包围盒实时量出，只读一行），下面「**目标尺寸**」两个数值格填宽或高（cm，精确到 0.01）即可整片缩放；勾上**等比缩放**时只填一个轴，另一个轴按比例跟随。

**倒圆角**块：填半径（cm）后按「倒圆角」，把这张片当前所有尖角一次倒成圆弧（缝合区间按边长占比自动接续）。

**生产**块：只放生产标记，**布纹线角度 / 位置 / 长度**（§7 表格「布纹线」一行）。

缩放会带走曲线控制柄、圆弧的圆心与半径、内部线、省尖、注释和各码放缩量；带圆弧边的片只能等比缩放，与其它片共用顶点的片要先「结构 ▸ 断开选中顶点」再缩放（§3.2）。

### 9.3 模拟器：面料物理与布料网格

**面料物理**块编辑这张片所用那份材质的力学参数（拉伸 / 弯曲 / 剪切 / 折痕刚度、克重、阻尼，见 [04-布料模拟](./04-布料模拟.md) §2）。**布料网格**块给出这张片的**网格密度**（0.5–10 cm，步长 0.5，默认 1.5；改它只重建这一片，见 §10）与**碰撞层**（0–9 的整数，0 为最内层，见 [04-布料模拟](./04-布料模拟.md) §4）。

### 9.4 生成器：着装

**着装**块写出这张片生成时的摆放方式：模板生成的片写作「环绕 躯干 / 手臂 / 腿 / 领口」，未指定着装方式的片显示「自动推断」——按片名判断（名字里含「袖」的走手臂，含「后」的走后半圈）；有手工摆放记录的片另有「手动放置：平面摆放」一行。

### 9.5 工程：尺码

尺码表是工程级设置，在**工程**标签底部（§8），含改名、↑↓ 调序、设基码、用此码与删除，所有版片共用同一套码。

### 9.6 逐边缝份与缝型

> **注**：「缝份量（本片默认）」改动会重建布料并重置模拟。也可以**逐边**设缝份：选中一条边，「边」区块给出边类型（只读）、长度（可键入目标边长，改的是这条边的终点）、圆弧边的**半径**与**圆心角**（两端点保持不动，§11.3）、**与邻边夹角**（1–179°，先选参照邻边）、**语义**（自由边 / 脚口 / 领口 / 袖窿 / 侧缝 / 肩线 / 袖山 / 腰节 / 省道 / 内部）、缝份（此边）（0–2 cm；调过即只覆盖这一条边的整片值）与角型（尖角 / 圆弧 / 斜角）。

缝型与线色的调整在 [03-缝合与着装](./03-缝合与着装.md) §2。

## 10. 布料密度

- 每张版片都有自己的**网格密度**（模拟器标签「布料网格」区块，0.5–10 cm，步长 0.5，默认 1.5）：数值越大，布料网格越疏、计算越快、褶皱越粗；越小越细腻但越慢。提交后只重建这一片，模拟回到初始状态（未着装）。
- 工程标签的**全局网格边长**（0.5–10 cm，步长 0.5，默认 1.5）是批量设置：松手后把所有版片的网格密度改成该值并重建全部布料，模拟回到初始状态。之后仍可逐片调整。
- 模板与新建版片默认使用 1.5 cm；一件服装的布料网格点控制在 5000~10000 之间能获得流畅的实时体验，最常用的手段是把全局网格边长调大，或只把大片的网格密度调大。

## 11. 当前不支持

### 11.1 收省与姿态

收省不会自动计算省量守恒：省量仍需手动填写，闭合只是把两条省边缝在一起（模拟效果见 §6.3）。模特也没有姿态动画：姿势由姿态预设与「模特」区块的三组滑条静态设定，没有逐关节编辑，改动即重建模特、布料与模拟状态（[03-缝合与着装](./03-缝合与着装.md) §4、§6）。

### 11.2 按尺寸求解的形状编辑

可以直接键入的尺寸只有两类：一条边的**边长**、**与邻边夹角**与圆弧边的**半径 / 圆心角**（对象标签「边」区块，夹角先选参照邻边），以及一张片按包围盒的**目标尺寸**（对象标签「尺寸」区块，§9.2）。

曲线简化在结构菜单（§3.2）。除此之外没有全局的按尺寸求解器——改一个尺寸不会连带解算其它约束，复杂调整仍靠拖点、拖手柄与放码。

### 11.3 圆弧边的编辑方式

圆弧边不提供圆心坐标与起止角的分别输入，属性面板「边」区块的**边类型**行也是只读的。弧从这些入口产生：

- 「圆」工具（整圈切成四段弧）。
- 「倒圆角」与「接角圆顺」。
- 「简化曲线」把采样折线降成弧。
- DXF 导入。

选中圆弧边后，「边」区块多出**半径**（cm）与**圆心角**（°）两个数值格，可在两端点不动的前提下改弧。改半径时圆心落在保持原方向的一侧，半径小于弦长一半会被夹到半圆；改圆心角时半径随之求出，扫掠方向（顺时针／逆时针）不变。两格都提交为一条可撤销命令。

弧始终连接它的两个端点：整片平移时随刚体移动；只拖一个端点时重新经过原来的中点（会被拉扁或推平）；端点被拖到与中点共线时这条边退回直线。切码与放码同样带着弧走。
