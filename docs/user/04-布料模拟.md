# 布料模拟

OpenCloth 实时算出布料在重力、风、模特碰撞下的下垂与褶皱。章节顺序依次为：播放控制与状态读数（§1）、面料参数与环境参数（§2、§3）、碰撞与检查、布料网格重建、故障排查（§4–§6）、当前不支持的功能（§7）、下一步（§8）。

## 1. 播放控制

底部时间轴居中的三个按钮：**重置**（`R`）、**播放 / 暂停**（`空格`）、**单步**（`.`），旁边是帧读数和速度档位。

### 1.1 按钮与模拟状态

> **注**：帧读数后面的「模拟时长」是累计的模拟时间（帧数 × 每帧步长，默认 1/60 秒），没有总长上限，可以一直跑下去；重置后归零。

| 右端状态提示 | 含义 |
| --- | --- |
| 未着装 — 播放或执行「自动着装」开始缝合 | 版型还是分离的环绕状态，此时按播放会先走着装动画 |
| 缝合着装中 | 正在缝合并贴回身体的动画阶段，重力不参与 |
| 模拟中 | 常规布料物理：重力、碰撞、褶皱 |
| 已暂停 | 停在当前形态 |

### 1.2 速度档位

**速度**下拉有 0.25x / 0.5x / 1x / 2x 四档，控制每秒推进的模拟步数：1x 每帧一步，0.5x 每两帧一步，0.25x 每四帧一步，2x 每帧两步。慢放时画面更新变慢，想逐帧检查仍可按 `.` 单步。

### 1.3 性能读数

时间轴左端是 3D 窗格的绘制读数，随显示模式变化：

- **光栅化**：`FPS(3D): 60`，即每秒实际绘制帧数。窗格可见时约等于显示器刷新率，被布局隐藏或不重绘时为 0。
- **光线追踪**：`SPP: 128/256  Cost: 12.4s`。分子是当前画面**每个像素**累计的采样次数，分母是「最大采样数」；分子越大噪点越少，等于分母后不再增长。`Cost` 是这一轮从第一个样本算到现在的秒数，达到最大采样数后停在最终值。
- **状态码**：拖动相机或播放模拟期间显示光栅画面、读数为 0，读数后写明当前受哪一项限制（`布料每帧在变` / `视角未静止` / `光追内核加载中` / `光栅过渡中` / `本机不支持`）。
- **重新累积**：画面停下后从 0 开始；计数到达 32 之前，屏幕上是光栅与光追按采样进度混合的过渡画面。

模拟运行时可以照常旋转、缩放 3D 相机，也可以实时改材质与物理参数——刚度、克重的改动直接作用在正在运行的布料上，不用重新运行。切到仅 2D 布局时模拟仍在继续。

## 2. 面料参数（模拟器标签）

选中一张版片后，模拟器标签编辑的是**这张片所指定的那份材质**的数值；多片共用一份材质时一起变（拆分方法见 [05-材质与渲染](./05-材质与渲染.md) §1）。所有滑条松手生效。

### 2.1 物理参数

| 参数 | 范围 | 调大时 |
| --- | --- | --- |
| 拉伸刚度 | 0–1 | 布料越不容易被拉长，贴身感弱一些 |
| 弯曲刚度 | 0–1 | 越挺括、褶皱越大且越少（牛仔、外套）；调小则柔软、细褶皱多（丝绸） |
| 剪切刚度 | 0–1 | 抵抗斜向拉伸，调高后围在身上不易产生斜向变形 |
| 折痕刚度 | 0–1（默认 0.85） | 只作用在用途为「折痕」的内部线上：调高后那片布料沿折线更容易折起并保持棱线，调成 0 则折痕线不再影响模拟 |
| 克重 | 50–600 g/m² | 克重越大，下垂越明显、形成褶皱越慢、惯性越大 |
| 阻尼 | 0–0.1 | 越大晃动衰减越快、越早静止 |

> **注**：阻尼按材质分别生效——每张版片读取它所用那份材质的阻尼，多片共用一份材质时一起变；未被任何版片覆盖的顶点沿用第一份材质。

### 2.2 面料起点

四档面料在「新增材质」时作为起点：

| 面料 | 特点 | 典型用途 |
| --- | --- | --- |
| 棉 | 中等刚度、适中垂坠 | T 恤、衬衫 |
| 丝绸 | 柔软、垂坠感强、褶皱细腻、克重最轻 | 连衣裙、丝巾 |
| 牛仔 | 硬挺、克重最大 | 牛仔裤、外套 |
| 针织 | 拉伸刚度低、有弹性 | 毛衣、运动服 |

所以同一件衣服可以让袖口用牛仔、衣身用棉：给不同的版片指定不同的材质即可（[05-材质与渲染](./05-材质与渲染.md) §1）。

## 3. 环境参数（工程标签 → 全局模拟）

| 参数 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 重力 | −20 ~ 0 m/s² | −9.8 | 只调竖直方向 |
| 风速 | 0 ~ 20 | 0（无风） | 风向固定沿世界 X 轴（侧向）吹，界面只给风速；布料带自然的逐点起伏，持续轻轻摆动而不是定住 |
| 迭代次数 | 1 ~ 15 | 5 | 越大布料越稳定、越不容易穿透，但性能开销更大；越小越快、越容易出现抖动 |
| 全局网格边长 | 0.5 ~ 10 cm | 1.5 | 把所有版片的网格密度设为该值。**松手后重建全部布料，模拟回到初始状态** |
| 布料自碰撞 | 勾选 / 不勾选 | 勾选 | 关掉后布料之间互相穿透（褶皱重叠、衣袖进衣身） |
| 布料厚度（cm） | 0 ~ 1 | 0.2 | 布料离模特表面与地面的最小间隙；调大后布料整体离体稍远，也决定自碰撞同层顶点的最小间距 |
| 层间距（cm） | 0 ~ 2 | 0.4 | 碰撞层每差 1 层，两层布料之间额外分开的距离（§4） |

风速、重力、迭代次数、自碰撞、厚度与层间距都实时生效；只有全局网格边长需要重建。子步长与固定时间步没有界面入口，模拟始终以 1/60 秒步长、每帧 4 个子步推进。

## 4. 碰撞与检查

| 对象 | 行为 |
| --- | --- |
| 模特 | 布料不会穿透模特，碰撞体随模特尺寸自动重建。选中模特后模拟器标签「布料与模特碰撞」可以关掉，关掉后布料穿身而过，可用来观察衣服内部 |
| 地面 | 带网格的地面始终生效，布料落地后停在上面并受摩擦，不会继续滑动；地面高度不可调 |
| 布料自身 | 默认开启自碰撞：同层布料至少隔一个「布料厚度」，不同碰撞层再按「层间距 × 层差」分开。可在工程标签勾掉「布料自碰撞」 |
| 参考物体 | 不参与碰撞，布料会穿过它 |

- **碰撞层**：选中版片后在模拟器标签的「布料网格」区块设置，0 是最内层，0–9 的整数。相邻层差 1 就多分开一个层间距；把外衣设为 1、内衣保持 0，外衣就会被推在内衣外面。层差越大分离越远，但超过约 2 cm 的目标距离不再继续加大。
- **性能代价**：自碰撞是每帧回读之后的一次 CPU 近邻投影，顶点越多、褶皱越密越慢；每帧最多处理 16 万个候选对，超出后当帧不再继续推开，不会无限拖慢帧率。布料大量重叠时关掉它能明显变快。
- 自碰撞只推开位置，法线沿用的是推开之前那一帧的结果，因此重叠刚被分开的瞬间光照可能略带滞后，属于正常现象。

> **注**：模特碰撞是一组贴合身体的胶囊近似，因此极贴身造型下可能有几毫米的穿透；想检查碰撞体是否贴合，用「线框」显示模式看（[05-材质与渲染](./05-材质与渲染.md) §3）。

### 4.1 合身热图

渲染标签的「显示模式」里选「合身热图」，就把布料顶点到模特碰撞体的间隙画成热图，用来判断哪里过紧、哪里悬空；选中后下方出现阈值、读数与导出：

- 红色是穿透（间隙为负），橙色是贴着身体（小于**贴近阈值**），绿色是合适，蓝色是悬空（大于**宽松阈值**）。
- **贴近阈值**默认 0.5 cm（0–3 cm），**宽松阈值**默认 2.5 cm（0.5–8 cm）；两个阈值只改变配色与统计，不改变碰撞。
- 读数给出**顶点**数、**穿透 / 贴近 / 合适 / 宽松**四类数量，以及**最小 / 平均 / 最大**间隙。统计每 6 帧刷新一次，暂停时也能看当前形态。
- **导出合身报告 CSV** 下载「工程名-合身报告.csv」，内容为工程名、日期、阈值与上面这组读数。
- 隐藏的版片不参与绘制，但它的顶点仍计入统计；关掉版片显示可以只看关心的部分。
- 选回光栅化、线框等其它显示模式即恢复面料材质；从光线追踪切到合身热图会自动回到光栅化。

> **注**：热图测的是到碰撞胶囊的距离，不是布料压力；间隙为负说明顶点已进入胶囊内部，通常来自极贴身造型或刚发生过大幅变形。

### 4.2 应变热图

渲染标签的「显示模式」里选「应变热图」，就把每个布料顶点相邻边的长度变化画成第二张热图，用来判断布料哪里被拉伸、哪里被压缩：

- 蓝色是受压缩（边长比静止时短），白色是无变形，红色是被拉伸（边长比静止时长）；基准取 2D 版型的静止几何，数值是按顶点平均的边长变化率。
- **色标下限**（−1 ~ 0）与**色标上限**（0 ~ 1，步长均为 0.05）只改变配色范围，不改变模拟。
- 读数给出**最小 / 最大 / 平均应变**（平均取绝对值），每 6 帧刷新一次，暂停时也能看当前形态。
- **导出应变报告 CSV** 下载「工程名-应变报告.csv」，内容为工程名、日期、色标范围与这组读数。

> **注**：「应变热图」与「合身热图」互斥，选一个会自动离开另一个。应变看布料自身的拉扯与压缩程度，间隙看布料与模特的距离（§4.1）。

## 5. 重建布料网格

3D 窗格工具条的「**重建网格**」：用当前工程重新生成布料并回到初始状态（未着装）。

改变版型、模特尺寸、网格密度时会自动触发同样的重建；已打好的 PIN 会保留。

### 5.1 编辑预览

3D 窗格工具条最右的「**编辑预览**」决定在 2D 里拖动版片时，布料是否跟着动。三档：

| 档位 | 拖动中 | 松手提交后 | 代价 |
| --- | --- | --- | --- |
| **关闭**（默认） | 布料不动 | 按 §5 重建 | 无 |
| **低精度** | 布料按粗网格跟随拖动 | 重新垂坠一次 | 每帧重算整块布料网格，松手后形态会重新计算 |
| **全精度** | 布料按工程自己的网格密度跟随拖动，并保持当前垂坠 | 增量重建，通常不重置模拟 | 只重算被拖的那片，开销中等 |

- 「低精度」那一行的悬停提示写着「粗网格跟随拖动，松手后布料重新垂坠；全精度沿用当前垂坠状态。」
- 预览只用于查看形状，**不会**提交改动：松手才生成一条可撤销的移动命令。一次拖动无论中间预览多少帧，都只算一步撤销。
- 预览每帧最多重画一次，鼠标移动再快也不会连续触发重建；期间 PIN 与播放状态不受影响，但粗网格预览时布料不能同时写入新的模拟结果，所以正在播放会出现短暂停顿——这是分辨率不匹配时的保护，不是故障。
- 想完全避免增加 GPU 负载就选「关闭」；查看版型改动对立体形态的影响就选「全精度」。

## 6. 出问题怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 布料散开、画面停住不动 | 参数太极端（刚度过高、克重过低、风速过大）导致求解发散，画面停在最后一个正常形态 | 调低刚度、调大克重、把风速归零，然后按 `R` 重置 |
| 布料滑过身体 | 碰撞体没贴合，或碰撞被关掉 | 确认「布料与模特碰撞」已勾选；模特尺寸改动后等它重建完成 |
| 褶皱生硬、折角尖锐 | 网格边长太大、弯曲刚度太高 | 全局网格边长调小，或弯曲刚度调低 |
| 帧率低、操作卡顿 | 布料网格太密或迭代太多 | 全局网格边长调大、迭代次数调低 |
| 拖动版型时卡顿 | 「编辑预览」开着「全精度」且片数多 | 换成「低精度」或「关闭」（§5.1） |
| 衣服持续晃动 | 阻尼太小 | 调大该片材质的阻尼，或提高迭代次数 |
| 外衣陷进内衣、两层布料重叠 | 碰撞层相同或「层间距」太小，或自碰撞被关掉 | 勾选「布料自碰撞」，给外衣设更大的碰撞层，或调大层间距（§4） |
| 版片一模拟就消失 | 数值发散，或该帧算出了非法值 | 按 `R` 重置并回到更温和的参数；持续出现就把网格调粗 |

顶点数偏多时优先调网格边长，目标区间见 [02-版型设计](./02-版型设计.md) §10。模拟与渲染共用显卡，独立显卡体验明显更好。

## 7. 当前不支持

- 布料与参考物体的碰撞。
- 时间轴定位到某一帧：只能播放、单步或重置，没有可拖动的进度头。
- 保存或导出模拟过程中的动画序列。
- 风的方向调节与阵风强度：风向固定，界面只给速度。
