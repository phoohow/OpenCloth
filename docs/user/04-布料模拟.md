# 布料模拟

OpenCloth 实时算出布料在重力、风、人体碰撞下的下垂与褶皱。这篇不讲原理，只讲**每个滑条往哪个方向调、会看到什么**：

- 播放控制与状态读数（§1）。
- 面料参数与环境参数（§2、§3）。
- 碰撞、重建布料网格与出问题时的排查（§4–§6）。

## 1. 播放控制

底部时间轴居中的三个按钮：**重置**（`R`）、**播放 / 暂停**（`空格`）、**单步**（`.`），旁边是帧读数和速度档位。

> **注**：进度条按 300 帧的长度显示，但模拟不会在第 300 帧停下，可以继续跑。

| 右端状态提示 | 含义 |
| --- | --- |
| 未着装 — 播放或执行「自动着装」开始缝合 | 版型还是分离的环绕状态，此时按播放会先走着装动画 |
| 缝合着装中 | 正在缝合并贴回身体的动画阶段，重力不参与 |
| 模拟中 | 常规布料物理：重力、碰撞、褶皱 |
| 已暂停 | 停在当前形态 |

**速度**下拉有 0.25x / 0.5x / 1x / 2x 四档，但每帧推进的步数是 `max(1, round(速度))`：0.25x、0.5x 与 1x 都是每帧一步，只有 2x 是每帧两步——慢放暂不可用，想慢看过程就单步按 `.`。

时间轴左端是 3D 窗格的绘制读数：光栅化时 `FPS(3D): 60`（每秒实际绘制帧数，窗格可见时约等于显示器刷新率，被布局隐藏或不重绘时为 0）；切到「光线追踪」后同一位置改为 `SPP: 128/256  Cost: 12.4s`：分子是当前画面**每个像素**累计的采样次数，分母是「最大采样数」，分子越大噪点越少，等于分母后不再增长；`Cost` 是这一轮从第一个样本算到现在的秒数，攒满后停在最终值，之后画面不变就不会继续涨。拖动相机或播放模拟期间显示的是光栅画面、读数为 0；画面停下后从 0 重新开始累积，所以计数不会一边拖动一边往上走。计数到达 32 之前，屏幕上是光栅与光追按采样进度混合的过渡画面。

模拟运行时可以照常旋转、缩放 3D 相机，也可以实时改材质与物理参数——刚度、克重的改动直接作用在正在运行的布料上，不用重跑。切到仅 2D 布局时模拟仍在继续。

## 2. 面料参数（物理标签）

选中一张版型片后，物理标签编辑的是**这张片所指定的那份材质**的数值；多片共用一份材质时一起变（拆分方法见 [05-材质与渲染](./05-材质与渲染.md) §1）。所有滑条松手生效。

| 参数 | 范围 | 调大时 |
| --- | --- | --- |
| 拉伸刚度 | 0–1 | 布料越不容易被拉长，贴身感弱一些 |
| 弯曲刚度 | 0–1 | 越挺括、褶子又大又少（牛仔、外套）；调小则柔软、细褶多（丝绸） |
| 剪切刚度 | 0–1 | 抵抗斜向拉伸，调高后围在身上不易拧巴 |
| 克重 | 50–600 g/m² | 越沉，下垂越明显、起褶越慢、惯性越大 |
| 阻尼 | 0–0.1 | 越大晃动衰减越快、越早静止 |

> **注**：阻尼是全局的——它只取工程里第一份材质的数值。改了第二份、第三份材质的阻尼不会有效果。

四档面料在「新增材质」时作为起点：

| 面料 | 特点 | 典型用途 |
| --- | --- | --- |
| 棉 | 中等刚度、适中垂坠 | T 恤、衬衫 |
| 丝绸 | 柔软、垂坠感强、褶皱细腻、克重最轻 | 连衣裙、丝巾 |
| 牛仔 | 硬挺、克重最大 | 牛仔裤、外套 |
| 针织 | 拉伸刚度低、有弹性 | 毛衣、运动服 |

所以同一件衣服可以让袖口用牛仔、衣身用棉：给不同的版型片指定不同的材质即可（[05-材质与渲染](./05-材质与渲染.md) §1）。

## 3. 环境参数（场景标签 → 全局模拟）

| 参数 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 重力 | −20 ~ 0 m/s² | −9.8 | 只调竖直方向 |
| 风速 | 0 ~ 20 | 0（无风） | 风向固定沿世界 X 轴（侧向）吹，界面只给风速；布料带自然的逐点起伏，持续轻轻摆动而不是定住 |
| 迭代次数 | 1 ~ 15 | 5 | 越大布料越稳定、越不容易穿透，但更吃性能；越小越快、越容易抖 |
| 全局网格边长 | 0.8 ~ 3 cm | 1.5 | 决定布料网格疏密。**松手后重建全部布料，模拟回到初始状态** |

- 风速、重力、迭代次数都实时生效；只有全局网格边长需要重建。
- 子步长与固定时间步没有界面入口，模拟始终以 1/60 秒步长、每帧 4 个子步推进。

## 4. 碰撞

| 对象 | 行为 |
| --- | --- |
| 人体 | 布料不会穿透模特，碰撞体随人体尺寸自动重建。选中模特后物理标签「布料与人体碰撞」可以关掉，关掉后布料穿身而过，可用来观察衣服内部 |
| 地面 | 带网格的地面始终生效，布料落地后停在上面并带摩擦，不会滑走；地面高度不可调 |
| 布料自身 | **没有布料之间的自碰撞**：褶皱互相叠进去、衣袖贴进衣身属于预期表现 |
| 参考物体 | 不参与碰撞，布料会穿过它 |

> **注**：人体碰撞是一组贴合身体的胶囊近似，因此极贴身造型下可能有几毫米的卡入；想检查碰撞体是否贴合，用「线框」显示模式看（[05-材质与渲染](./05-材质与渲染.md) §3）。

## 5. 重建布料网格

3D 窗格工具条的「**重建网格**」：用当前工程重新生成布料并回到初始状态（未着装）。

- 改变版型、人体尺寸、全局网格边长时会自动触发同样的重建。
- 你已经打好的 PIN 会保留。

## 6. 出问题怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 布料炸开、画面卡住不动 | 参数太极端（刚度过高、克重过低、风速过大）算崩了，画面停在最后一个正常形态 | 把刚度往回调、克重加大、风速归零，然后按 `R` 重置 |
| 布料滑过身体 | 碰撞体没贴合，或碰撞被关掉 | 确认「布料与人体碰撞」已勾选；人体尺寸改动后等它重建完成 |
| 褶皱很粗、像纸板 | 网格边长太大、弯曲刚度太高 | 全局网格边长调小，或弯曲刚度调低 |
| 帧率低、操作发涩 | 布料网格太密或迭代太多 | 全局网格边长调大、迭代次数调低 |
| 衣服一直晃不停 | 阻尼太小 | 阻尼往上调（记得改的是第一条材质记录的阻尼），或提高迭代次数 |
| 版片一模拟就消失 | 数值发散，或该帧算出了非法值 | 按 `R` 重置并回到更温和的参数；持续出现就把网格调粗 |

- 粒子数偏多时优先调网格边长，目标区间见 [02-版型设计](./02-版型设计.md) §6。
- 模拟与渲染共用显卡，独立显卡体验明显更好。

## 7. 当前不支持

- 布料自碰撞、布料与参考物体的碰撞。
- 逐片不同的阻尼。
- 慢放（0.25x / 0.5x 与 1x 实际相同）。
- 时间轴定位到某一帧：只能播放、单步或重置，没有可拖动的进度头。
- 保存或导出模拟过程中的动画序列。
- 风的方向调节与阵风强度：风向固定，界面只给速度。
