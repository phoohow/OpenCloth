# 缝合与着装

版型片要靠 **缝合（Seam）** 拼接成完整服装，再通过 **自动着装（Draping）** 穿到人体上。这篇讲：

- 缝合关系从哪来、能调哪些缝纫参数（§1、§2）。
- 着装动画如何发生，以及配套的假缝点与 PIN（§3）。
- 与之搭配的人体模型与参考物体（§4、§5）。

## 1. 缝合从哪里来

缝合关系由**模板**提供：在左侧模板库点「应用」或「追加」，前后片的侧缝、肩线、袖山、袖下缝会一并生成，不需要手工连线。工具条上的「缝合」按钮只切换缝线连接的**显示**。

| 想看 / 想改 | 位置 |
| --- | --- |
| 看配对关系 | 点工具条「缝合」，2D 视图里用彩色虚线画出每条缝口两端的对应关系；再点一次收回 |
| 看真实参与模拟的缝线 | 3D 窗格里连接两片互相配对位置的连线，颜色就是这条缝口的**线色**（模板默认红色）；随着缝合收紧、贴合，连线会淡出消失 |
| 逐条缝口隐藏或改线色 | 场景树「缝纫线」集合，每条缝口一行（行名是它连接的两张版型片，行尾是缝型） |

缝型标记的是这条缝口的意图：

| 缝型 | 界面含义 | 模拟中的实际行为 |
| --- | --- | --- |
| 普通缝合 | 两条边按走向对齐拼接（侧缝、肩线） | 三种缝型建立的是同一种缝合约束：把配对的粒子对拉到彼此的静止长度 |
| 缩缝 | 一边较长，缝合时均匀收缩到较短边（如袖山吃势） | 同上——收缩量由两条边的实际长度差决定，与选的是哪种缝型无关 |
| 开放边 | 下摆、领口这类不该拼起来的边 | 同上——这些边之所以自由，是因为模板没为它们建缝口记录，而不是缝型起了作用 |

> **注**：求解器不读缝型，它是给人看的标签（只有离线预览会把它印在缝线标注上）；要不要拼、拼得对不对，取决于有没有这条缝合记录以及两边走向是否相配。走向配反时布料会扭转，唯一的纠正入口是这条缝口的「乙边反向」，配不出来时用模板重新生成版型最省事。

## 2. 能调的缝纫参数

| 参数 | 位置 | 范围与默认 | 改动后 |
| --- | --- | --- | --- |
| 缝份量 | 对象标签 · 版型片 · 模拟 | 0–2 cm，默认 1 | 重建布料并重置模拟 |
| 显示缝线 | 场景树缝线行的眼睛，或对象标签 · 缝纫线 | 开 / 关 | 只影响视口显示，缝合约束照旧、模拟照旧 |
| 线色 | 对象标签 · 缝纫线 | 颜色选择器 | 同时作用于 2D 指示线与 3D 叠加层；与下面三项走同一条保存路径，也会重建布料 |
| 缝型、缝合强度、乙边反向 | 对象标签 · 缝纫线 | 见下 | 重建布料并重置模拟 |

- **缝合强度** 0.05–1：数值越高缝线越硬。它只改变缝线的软硬，**不会**做"受力过大崩开"的断裂模拟。
- **乙边反向**：配对前把乙边的顶点顺序反过来。两条边的走向相反时才需要打开。

缝线的粗细没有界面控件。

## 3. 自动着装（Draping）

### 3.1 三阶段动画

1. 焦点放在 3D 窗格（默认布局的左侧窗格，或按 `1` 切到全屏 3D）。
2. 按 `Ctrl+D` 自动着装，或直接按 `空格` 播放、按 `.` 单步——未着装时这三种方式都会先走着装动画。
3. 画面是一气呵成的动画，约一秒钟，分三个阶段：

| 时点 | 画面 |
| --- | --- |
| 起点：未缝合 | 每片版型各自环绕在人体周围（前片在胸前、后片在背后、袖子在手臂），沿人体向外的水平方向离开体表约 7 cm，片与片之间留出开口；缝线连出配对关系，一眼能看出谁和谁拼 |
| 第一阶段：缝合 | 缝线长度从敞开距离收缩到零，版片被拉动彼此靠拢；某条缝线合拢后该连线淡出消失 |
| 第二、三阶段：着装与松弛 | 缝合完成的整件服装沿引导轨迹贴回体表，人体碰撞把布料推到身上，最后做一次无重力的松弛收敛 |

- 三阶段走完后时间轴显示「模拟中」，此后每一帧都是常规布料物理：重力、碰撞、褶皱。
- 按 `R`（或时间轴的「重置」按钮）回到分离未缝合的初始状态，缝线重新出现；你已经打好的 PIN 会被保留。

### 3.2 假缝点与 PIN

版型片生成时，**环绕人体的片**顶部约 12% 高的一条会被自动固定，相当于假缝——所以未着装时版片能稳定悬在身体周围而不滑落。

- 袖子不假缝，它靠袖山缝合悬吊。
- 平铺摆放的片也不假缝。

| 想做什么 | 方法 |
| --- | --- |
| 临时固定一点 | 选工具条 **打PIN**后左键点击布料，或任何时候 `Alt + 点击` |
| 释放单点 | **拔PIN**，或 `Alt + Shift + 点击` |
| 全部释放 | 工具条「清除PIN」，见下方说明 |

- 每个 PIN 在 3D 里显示成跟随布料的小黄点，数量不限。
- 点落在你点击的那片布料上、离点击处最近的网格点上，贴着的双层布料不会打到里层。
- 点已经假缝住的部位也会落下小黄点（那颗点本来就固定），拔 PIN 会把它连同假缝固定一起解除。
- 工具条上的 `PIN 徽标：3 · 固定 1204` 是「你打的小黄点数 · 当前固定点总数」，后者包含顶部假缝带，所以数字比看上去大得多。

> **注**：「清除PIN」把假缝点与你手动打的点一次性批量释放，不需要逐点等待，按下即生效；衣服可能整片下滑，按 `R` 即可恢复。

### 3.3 初始位置与常见问题

若自动着装后版型位置不理想：

1. 在场景树选中版型片。
2. 用对象标签「变换」的位置 / 旋转 / 缩放调整它相对人体的初始摆放（松手后重建布料并重置模拟）。
3. 再执行自动着装。

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 布料穿透人体 | 初始位置与身体重叠，或碰撞被关掉 | 调整初始位置让版型在体表外侧；确认物理标签里「布料与人体碰撞」已勾选 |
| 服装扭转 | 缝合两边的走向相反 | 用模板重新生成版型 |
| 着装后散架 | 有一对边没拼上，或两条边的角度区间、走向不匹配 | 点工具条「缝合」检查配对是否齐全；确认无误仍散架时用模板重新生成版型 |
| 衣服滑落 | 顶部假缝点被清掉了 | 按 `R` 重置，或重新打 PIN |
| 袖子位置怪 | 袖子靠袖山悬吊，没有假缝带 | 正常现象；调肩宽 / 袖山参数或加 PIN 固定 |

## 4. 人体模型（Avatar）

起步工程默认是内置的**女性人体**（身高 170 cm、胸围 92 / 腰围 70 / 臀围 92）。在场景树选中「模特」后：

| 想做什么 | 位置 |
| --- | --- |
| 换模特 | 对象标签 · 模特 · 「模特」下拉：女性人体 / 专业人体 / 标准人体 / 程序人台。切换时会一并套用该体型的三围尺寸 |
| 导入自定义模特 | 「导入模特」按钮，或 文件 → 导入 → 模特模型…，支持 `.glb` / `.gltf` / `.obj`（选 `.gltf` 时要连同它的附属文件一起选中）。导入的模型按身高归一化、底部落地，碰撞体随其尺寸自动重建。导入是**可撤销**的一步操作；导入后「模特」下拉会多出「自定义：<文件名>」条目，撤销即回到之前的模特 |
| 调体型 | 「人体」区块的滑条：身高 140–200 cm、胸围 60–140、腰围 50–130、臀围 60–150、手臂外展 0–45°。尺寸改动会重建人体、布料与模拟状态 |
| 看清服装与身体的关系 | 「显示效果」选半透明；行首的可见性勾选决定人体画不画 |
| 整体移动人体 | 与版片、参考物一样，选中「模特」行后可用对象标签的「变换」拖位置 / 旋转 / 缩放三轴 |
| 关掉碰撞 | 物理标签只有一个选项「布料与人体碰撞」，关掉后布料会穿过身体，方便观察服装内部结构 |

> **注**：碰撞体是一组贴合身体的**胶囊**近似，不是逐像素的身体模型——极贴身造型下褶皱卡进身体几毫米属正常，可用线框模式检查胶囊是否贴合（[05-材质与渲染](./05-材质与渲染.md) §3）。

## 5. 参考物体

文件 → 导入 → 参考物体…（`.glb` / `.gltf` / `.obj`）可以在场景里摆一个包、一件已有衣服或任意道具作参照。参考物体：

- **保持文件原始尺寸与高度**，不按身高归一化，但水平方向会**居中到场景原点**（x/z 归心）；需要摆位用对象标签的「变换」移动、旋转、缩放。
- **默认半透明**（「透明度」滑条 0.05–1）。
- **不参与布料碰撞**，布料会直接穿过它，只用于比对比例与造型。
- 用完可以在「参考物」区块点「删除参考物体」，或 文件 → 导入 → 清除全部参考物体。导入、删除、清除都是**可撤销**的一步操作；被删除的模型文件会在下次打开其它工程时从本地存储回收。

## 6. 当前不支持

- 手工新建缝合关系（界面只能改已生成缝口的参数）。
- 缝线粗细与松紧的独立控件（松紧由「缝合强度」承担）。
- 布料之间的自碰撞：衣袖贴进衣身、褶皱互相叠进去属预期表现。
- 布料与参考物体、与地面的自定义碰撞层（地面始终生效且高度固定）。
- 服装随人体姿势变化：人体是固定站姿，没有姿态编辑。
