# 缝合与着装

版片要靠 **缝合（Seam）** 拼接成完整服装，再通过 **自动着装（Dressing）** 穿到模特上。章节顺序依次为：缝合的来源与可调参数（§1、§2）、自动着装与固定点 PIN（§3）、模特模型与参考物体（§4、§5）、当前不支持的功能（§6）、下一步（§7）。

## 1. 缝合从哪里来

### 1.1 缝合的入口

缝合关系有这些入口：

- **模板**：在左侧模板库点【替换版型】或【追加版型】，前后片的侧缝、肩线、袖山、袖下缝会一并生成，不需要手工连线。
- **缝合工具**：选工具条【缝合】，在 2D 里沿甲边按住拖动选中一段区间、松手，再沿乙边拖出对应区间，两条边就缝上了（一步撤销）。整边缝合就沿边从头拖到尾；只单击不拖出长度不会成缝。
- **智能菜单**：工具条【智能】在【自动排位】下方直接列出算法按语义、长度、方向、曲率配好的候选（[02-版型设计](./02-版型设计.md) §3.5），点一行接受一条，或【全部接受（N 条）】一次接受全部。
- **结构菜单的多段缝合**：选中一条基准边和至少两条目标边，把基准边等分成段逐段缝合（如袖山对多段袖窿）。
- 通过【文件 → 导入 → JSON 版型…】带入的文件也可以自带缝合记录（DXF 导入不含缝合）。

### 1.2 查看与修改

| 查看 / 修改 | 位置 |
| --- | --- |
| 看配对关系 | 点工具条【缝合】，2D 视图里用彩色虚线画出每条缝口两端的对应关系；选中某条缝纫线或某条边时也会显示；换到别的工具收回 |
| 看真实参与模拟的缝纫线 | 3D 窗格里连接两片互相配对位置的连线，颜色就是这条缝口的**线色**（模板默认红色）；随着缝合收紧、贴合，连线会淡出消失 |
| 逐条缝口隐藏或改线色 | 场景树【缝纫线】集合，每条缝口一行（行名是它连接的两张版片，行尾是缝型） |

### 1.3 缝型的含义

缝型标记的是这条缝口的意图：

| 缝型 | 界面含义 | 模拟中的实际行为 |
| --- | --- | --- |
| 普通缝合 | 两条边按走向对齐拼接（侧缝、肩线） | 为这条缝口建立缝合约束，把配对的顶点对拉到彼此的静止长度 |
| 缩缝 | 一边较长，缝合时均匀收缩到较短边（如袖山吃势） | 同样建立缝合约束，且**缩缝比例**直接决定静止长度：缝纫线按【敞开距离 × 比例】留长，多出的长度就是吃量 |
| 开放边 | 下摆、领口这类不该拼起来的边 | 不为这条缝口建立约束，两侧在模拟里各自自由 |

> **注**：三种缝型都影响模拟：普通缝合与缩缝建立约束，开放边跳过该缝口不缝合。走向配反时布料会扭转，纠正入口是这条缝口的【乙边反向】；配不出来时用模板重新生成版型。

## 2. 能调的缝纫参数

在场景树【缝纫线】集合或 2D 里选中一条缝纫线，对象标签给出【缝纫线】与【缝合】两个区块。

### 2.1 缝合参数

| 参数 | 位置 | 范围与默认 | 改动后 |
| --- | --- | --- | --- |
| 缝份量（本片默认） | 对象标签 · 版型（或逐边：对象标签 · 边） | 0–2 cm，默认 1 | 裁片轮廓变宽，重建布料并重置模拟 |
| 缝纫线可见性 | 场景树缝纫线行的眼睛，或对象标签 · 对象 · 【可见性】勾选 | 开 / 关 | 2D 缝合指示线与 3D 缝纫线一起隐藏或恢复；缝合约束照旧、模拟照旧，隐藏的缝口在 2D 里也点不中 |
| 线色 | 对象标签 · 缝合 | 颜色选择器 | 同时作用于 2D 指示线与 3D 叠加层 |
| 缝型 | 对象标签 · 缝合 · 下拉 | 普通缝合 / 缩缝 / 开放边 | 普通缝合与缩缝重排该缝的约束；开放边撤掉约束，该缝口两侧保持自由。都只重排约束，不重建布料、不重置模拟 |
| 缝合强度 | 对象标签 · 缝合 | 0.05–1 | 只重排该缝的约束，顶点状态保留 |
| 乙边反向 | 对象标签 · 缝合 | 开 / 关 | 配对顺序反过来；不重建布料、不重置模拟 |
| 缝合区间 | 对象标签 · 缝合 · 甲起点 / 甲终点 / 乙起点 / 乙终点四条滑条 | 0–1，步长 0.01，两端至少相隔 0.01；【甲区间】【乙区间】行按百分比显示当前值 | 把缝口收窄到边的子段，约束随之重排 |
| 对位点 | 对象标签 · 缝合 · 【对位点】勾选 + 【甲对位】【乙对位】两条滑条 | 默认落在区间中点，取值被夹在各自区间内 | 这条缝按一对锚点分成两段分别对位，吃势分布在锚点两侧；2D 用黄色短线与两个圆点画出这对锚点 |
| 缩缝比例 | 对象标签 · 缝合（仅缝型为【缩缝】时出现） | 0.5–1 | 改写这条缝的静止长度，决定留多少吃势 |

**缝合强度**只改变缝纫线的软硬，**不会**模拟受力超过阈值后的断裂；**对位点**要甲乙两侧同时给定才生效。

缝纫线的粗细没有界面控件。刀口（[02-版型设计](./02-版型设计.md) §7）是缝口两端的对位记号，画在 2D 轮廓上并随 DXF / SVG 出片，模拟本身不读取它；要把一条缝按点位对齐，用【对位点】。

### 2.2 缝合警告

工具条【检查】会把缝合的可疑之处单列成**警告**行（行首写【警告：】），点一行直接选中那条缝口去改：

| 警告 | 什么时候报 | 怎么处理 |
| --- | --- | --- |
| 两侧长度差 | 被缝的那一段两边采样弧长相差超过 0.3 cm、且超过较长一边的 2%；消息里写出甲乙两个读数 | 缩缝和收省不报，所以报了多半是配对区间或边选错了：改【甲/乙区间】到真正要缝的那一段，或改成长度接近的边 |
| 重复配对同一对边 | 两条缝合配了同一对边（正反次序都算），且两侧的区间还重叠 | 删掉多余的那条（选中后用结构菜单删除，或删元素）；一条边分段来缝时把区间首尾相接就不会报 |

> **注**：警告只是提示，**不会阻止保存或提交**。长度差本身也可能是故意留的吃势，只有拓扑错误（区间非法、边丢失、同一边区间重叠等）才会让一次操作整体回退。

### 2.3 接角圆顺

两片布在缝口的**端点**处接成一个角，可先检查再改：

- **读数**：选中一条缝纫线，对象标签的【接角】区块给出【起点】【终点】两行，形如 `180.0° 顺直`、`150.0° 弯折 30.0°`、`168.2° 重叠 11.8°`。量的是缝合之后从这个角伸出去的两条轮廓边之间的夹角：两片在这处的角一样大就成一条直线（180°，顺直），不一样大就折出角；两片在这儿互相压住时标【重叠】。缝合端没有停在轮廓角点上时写【缝合端不在角点】。
- **预览**：2D 工具条【图层】里勾上【拼接预览】，被选中缝合的乙片会按缝合后的位置画成蓝色虚线（两片分居缝纫线两侧，就是拷边压平后的样子），接角处标出角度与弯折量，颜色绿（顺直）／黄（弯折）／红（重叠）。
- **改**：2D 工具条【结构】里的【接角圆顺：选中缝合的起点】与【接角圆顺：选中缝合的终点】，输入圆顺半径（默认 1.5 cm）。它给两片在接角处各倒一段相切的圆弧，缝合区间自动挪到剩下的边上，一次撤销同时退回两片的改动与缝纫线。

圆顺只去掉接缝处的尖角，**不改变**两片各自的角大小；夹角差得多时仍需改轮廓（缩短或放长对应的边）。半径大于相邻边长时提示【圆角半径过大，超出相邻边长】，工程保持原样。

## 3. 自动着装（Dressing）

### 3.1 三阶段动画

1. 焦点放在 3D 窗格（默认布局的左侧窗格，或按 `1` 切到全屏 3D）。
2. 按 `Ctrl+D` 自动着装，或直接按 `空格` 播放、按 `.` 单步；未着装时这三种方式都会先走着装动画。
3. 动画约一秒钟，分三个阶段：

| 时点 | 画面 |
| --- | --- |
| 起点：未缝合 | 每片版型各自环绕在模特周围（前片在胸前、后片在背后、袖子在手臂），沿模特向外的水平方向离开体表约 7 cm，片与片之间留出开口；缝纫线连出配对关系，一眼能看出谁和谁拼 |
| 第一阶段：缝合 | 缝纫线长度从敞开距离收缩到零，版片被拉动彼此靠拢；某条缝纫线合拢后该连线淡出消失 |
| 第二、三阶段：着装与松弛 | 缝合完成的整件服装沿引导轨迹贴回体表，模特碰撞把布料推到身上，最后做一次无重力的松弛收敛 |

三阶段走完后时间轴显示【模拟中】，此后每一帧都是常规布料物理：重力、碰撞、褶皱。按 `R`（或时间轴的【重置】按钮）回到分离未缝合的初始状态，缝纫线重新出现；已打好的 PIN 会被保留。

### 3.2 固定点（PIN）

模拟不预设任何固定点：三个着装阶段都靠缝合约束、身体碰撞与接触摩擦推进，着装完成后衣片也是全自由的，肩线和领口会随重力一起起褶。只有手打的 PIN 才会固定粒子。

| 想做什么 | 方法 |
| --- | --- |
| 打一个 PIN | 选工具条【打PIN】，指针移到布料上变成「圆圈 + 中心红点」时点击；或任何时候 `Alt + 点击` |
| 拔掉一个 PIN | 选工具条【拔PIN】，指针移到已有 PIN 上变成叉号、该点同时变红变大时点击；或 `Alt + Shift + 点击` |
| 全部释放 | 工具条【清除PIN】，见下方说明 |

- 被身体挡住的布料与 PIN 不会触发工具（和看不见的位置不该点一样）。
- 光标会告诉你此刻能不能打点/拔点：布料上是「圆圈 + 红点」=会打点，已有 PIN 上是叉号=会拔点，普通箭头=什么都不会发生，左键照常旋转视角。因此选了工具也仍然可以随时转动相机，只有指到布料/指到 PIN 时鼠标才被工具接管。
- 每个 PIN 在 3D 里显示成跟随布料的小黄点，数量不限；悬停到要拔的 PIN 上时它会变成红色并放大，确认后再点。
- 点落在被点击的那片布料上、离点击处最近的网格点上，贴着的双层布料不会打到里层。
- 工具条【打PIN】图标右侧的 `3` 是当前已打的小黄点数；固定点与小黄点一一对应，没有别的来源。

> **注**：【清除PIN】把当前所有固定点一次性批量释放，不需要逐点等待，按下即生效；衣服可能整片下滑，按 `R` 即可恢复。

### 3.3 初始位置与常见问题

若自动着装后版型位置不理想：

1. 在场景树选中版片。
2. 用对象标签【变换】的位置 / 旋转 / 缩放调整它相对模特的初始摆放（松手后重建布料并重置模拟）。
3. 再执行自动着装。

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 布料穿透模特 | 初始位置与身体重叠，或碰撞被关掉 | 调整初始位置让版型在体表外侧；确认模拟标签里【布料与模特碰撞】已勾选。碰撞每帧都会把落在身体内部的粒子推回表面，所以固定间隙之外的穿透会自己恢复 |
| 服装扭转 | 缝合两边的走向相反 | 选中该缝纫线，在对象标签【缝合】里打开【乙边反向】；两条边本身配对不上时用模板重新生成版型 |
| 着装后散架 | 有一对边没拼上，或两条边的角度区间、走向不匹配 | 点工具条【缝合】检查配对是否齐全；确认无误仍散架时用模板重新生成版型 |
| 衣服滑落 | 衣片没有缝口与身体支撑（例如缝合没配对就播放） | 用工具条【缝合】检查配对是否齐全，确认模拟标签里【布料与模特碰撞】已勾选；需要时加 PIN 固定 |
| 袖子位置怪 | 袖子只靠袖山缝口悬吊，缝口没有张力时袖山会塌 | 调肩宽 / 袖山参数，或加 PIN 固定 |

## 4. 模特模型（Avatar）

起步工程默认是内置的**女性模特**（身高 175 cm、胸围 92 / 腰围 70 / 臀围 110）。在场景树选中【模特】后：

| 想做什么 | 位置 |
| --- | --- |
| 改名 | 对象标签 · 对象 · 【名称】可改，场景树里的【模特】行跟着变 |
| 换模特 | 对象标签 · 【模型来源】区块的【模型】下拉：女性模特 / 专业模特 / 标准模特 / 程序模特。切换时会一并套用该体型的三围尺寸 |
| 导入自定义模特 | 【模型】下拉行尾的【+】，或【文件 → 导入 → 模特模型…】，支持 `.glb` / `.gltf` / `.obj`（选 `.gltf` 时要连同它的附属文件一起选中）。导入的模型按身高归一化、底部落地，碰撞体随其尺寸自动重建。导入是**可撤销**的一步操作；导入后【模型】下拉会多出【自定义：<文件名>】条目，撤销即回到之前的模特 |
| 调体型 | 对象标签【体型】区块的滑条：身高 140–200 cm、胸围 60–140、腰围 50–130、臀围 60–150 |
| 调姿态 | 对象标签【姿态】区块的三组滑条：手臂外展 0–90°、腿部开合 0–45°、躯干倾斜 ±20°，另有【自然】【A 型】【T 型】【侧立】四个姿态预设；体型或姿态改动都会重建模特、布料与模拟状态 |
| 调肤色 | 材质标签【皮肤】区块：肤色、肤色预设（浅肤 / 亚洲 / 暖棕 / 深肤）、粗糙度与高光；改动只重写人体材质，不重建模特（[05-材质与渲染](./05-材质与渲染.md) §1.3） |
| 看清服装与身体的关系 | 对象标签【对象】区块的【外观】选半透明；行首的可见性勾选决定模特画不画 |
| 整体移动模特 | 与版片、参考物一样，选中【模特】行后可用对象标签的【变换】拖位置 / 旋转 / 缩放三轴 |
| 关掉碰撞 | 模拟标签只有一个选项【布料与模特碰撞】，关掉后布料会穿过身体，方便观察服装内部结构 |

> **注**：碰撞体是模特的**可见网格**，不是逐像素的身体模型。极贴身造型下褶皱进入身体表面以内几毫米属正常，可用线框模式检查布料与身体的贴合情况（[05-材质与渲染](./05-材质与渲染.md) §3）。

## 5. 参考物体

【文件 → 导入 → 参考物体…】（`.glb` / `.gltf` / `.obj`）可以在场景里摆一个包、一件已有衣服或任意道具作参照。参考物体：

- **保持文件原始尺寸与高度**，不按身高归一化，但水平方向会**居中到场景原点**（x/z 归心）；需要摆位用对象标签的【变换】移动、旋转、缩放。
- **默认半透明**（【透明度】滑条 0.05–1）。行名在对象标签 · 对象 · 【名称】里改。
- **不参与布料碰撞**，布料会直接穿过它，只用于比对比例与造型。
- 用完可以在【参考物】区块点【删除参考物体】，或【文件 → 导入 → 清除全部参考物体】。导入、删除、清除都是**可撤销**的一步操作；被删除的模型文件会在下次打开其它工程时从本地存储回收。

## 6. 当前不支持

- 缝纫线粗细的独立控件（松紧由【缝合强度】承担）。
- 布料与参考物体、与地面的自定义碰撞层（地面始终生效且高度固定）。
- 任意姿态编辑与姿态动画：模特姿势只有【自然 / A 型 / T 型 / 侧立】预设与手臂外展、腿部开合、躯干倾斜三组滑条（§4），没有逐关节调整，也没有让服装跟随的姿态动画。

着装完成后即可进行布料物理模拟，让服装自然垂坠、产生褶皱，请阅读 [04-布料模拟](./04-布料模拟.md)。
