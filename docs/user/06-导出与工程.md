## 1. 工程文件（`.ocproj.json`）

OpenCloth 用 `.ocproj.json` 保存完整设计：版型片几何、缝合关系与缝份、材质与物理参数、人体模型与体型尺寸、灯光与渲染设置（含光线追踪与降噪参数）。

> **说明**：它保存的是**设计与参数**，不是模拟后的网格。重新打开后布料回到初始形态，需要再按一次播放或自动着装（`Ctrl+D`）重新试穿。

> **注**：导入的模特模型与参考物体**不在文件里**。工程只记住它们存在本机的哪个位置，把 `.ocproj.json` 发给同事或换一台电脑，这两类模型会显示成「文件已失效」，需要重新导入；内置的三种人体与环境图不受影响。不想让对方重新导入，可以在「模特」下拉里改用内置人体。

### 1.1 保存与打开

| 操作 | 方法 | 说明 |
| --- | --- | --- |
| 保存 | 文件 → 保存（`Ctrl+S`） | 浏览器下载一份「工程名.ocproj.json」。浏览器不会替你覆盖本地文件，多次保存就是多次下载，靠文件名区分版本 |
| 另存为 | `Ctrl+Shift+S` | 先询问工程名称（改名可撤销），再按新名字下载 |
| 打开 | 文件 → 打开…（`Ctrl+O`） | 选择 `.ocproj.json`，版型、缝合、材质与场景设置完整恢复 |
| 新建 | `Ctrl+N` | 空白的起步场景 |

- 当前工程有未保存的改动时，新建与打开会先问「当前工程有未保存的修改，确定放弃吗？」。
- 打不开通常是两种原因：文件来自更高版本（界面会提示不支持的工程版本），或必要字段缺失（提示无效的工程文件）。
- 旧工程里没有的字段——例如光线追踪与降噪参数、新版的光源列表——会按默认值补齐，不会报错。

### 1.2 最近打开

- 「文件 → 最近打开」列出最近在本机保存过的工程（最多 8 条，按时间倒序，显示名称与保存时间），点一条直接载入；底部「清除列表」清空这份记录。

> **注**：记录存在这台电脑的浏览器里，不随 `.ocproj.json` 文件走——换机器后需要重新打开一次工程。

### 1.3 自动保存

- 「文件 → 自动保存」选间隔：关闭 / 每 30 秒 / 每 1 分钟 / 每 5 分钟。**默认是关闭**，需要自己打开。
- 快照只保留**最近一份**，到点覆盖上一份，不是可以逐段回退的历史版本。
- 菜单栏右端常驻显示「自动保存 关闭」或「自动保存 30s · 最近一次快照时间」。
- 「立即保存快照」不用等间隔；「从快照恢复（时间）…」回到那份快照，没有快照时该项不可用。恢复后记得用 保存 / 另存为 落成正式文件。
- 快照只能在这台电脑的这台浏览器里找回；清浏览器数据会一并清掉。

## 2. 导出 3D 模型

导出的是**当前模拟状态下的布料快照**，入口在「文件 → 导出」子菜单，只有两项，没有额外选项对话框：

- **服装 GLB…**：下载「工程名.glb」。包含布料网格的顶点、面、UV、法线与 PBR 材质参数（基础色、粗糙度、金属度、光泽），Blender、Unity、Unreal、three.js 都直接支持。
- **服装 OBJ…**：下载「工程名.obj」。只有顶点、法线与面索引，**不生成 MTL 材质文件**；需要材质就用 GLB。

| 数据 | GLB | OBJ |
| --- | --- | --- |
| 布料网格顶点 / 面 | 是 | 是 |
| UV 坐标 | 是 | 否 |
| 法线 | 是 | 是 |
| 材质参数 | 是 | 否 |
| 面料贴图 | 否（当前没有贴图入口） | 否 |
| 人体模特、参考物体 | 不含 | 不含 |
| 选中高亮、PIN 小球、缝线 | 不含 | 不含 |

> **注**：GLB 会按布料**当前佩戴的材质**导出。线框、UV 检查和法线可视化会替换视口材质；想拿标准 PBR 成品，先切回「光栅化」或「光线追踪」再导出。

## 3. 导出图片

文件 → 导出 → **导出截图 PNG**，按当前 3D 视口分辨率下载「工程名.png」。画面里只有 3D 内容——服装、人体、地面、环境，**不含任何界面元素**。

- 选择「光线追踪」时，画面在动（拖动相机、播放模拟）导出到的是光栅帧，静止后才是渐进采样结果；建议在暂停且画面收敛后再导出（开了降噪就等它降噪完成、画面不再变化时导出）。
- 想换构图或分辨率，先用鼠标调整 3D 视口（或按 `1` 切到仅 3D 视口放大）再导出。
- 动画序列逐帧导出暂未提供；需要连续画面时可以逐帧单步（`.`）后分别导出，或导出 GLB 后在外部软件里渲染。

## 4. 与其他软件协作

| 目标软件 | 推荐格式 | 说明 |
| --- | --- | --- |
| Blender | GLB | 直接导入，保留材质参数，花型需重新赋 |
| Unity / Unreal | GLB | 可直接导入，或按插件需要转成 FBX |
| CLO3D / Marvelous Designer | OBJ | 作为参考网格导入 |
| 网页展示 | GLB | three.js / `<model-viewer>` 原生支持 |

## 5. 常见问题

**Q：导出的网格面数太高？**
A：在场景标签把「全局网格边长」调大（例如 2–3 cm），布料密度随之下降，重新模拟后再导出。

**Q：昨天做的工程今天找不到了？**
A：「文件 → 最近打开」与自动保存快照都只记录在本机浏览器里。养成用 `Ctrl+S` 下载 `.ocproj.json` 的习惯，并把自动保存间隔打开。

**Q：打开旧工程后光源变了？**
A：更早版本只有一盏主光加一盏补光，打开时会自动转成光源列表里的两盏方向光，画面效果保持一致，之后就能正常增删光源。

## 6. 当前不支持

- 直接覆盖本地文件（浏览器下载模型每次都是新文件）。
- 导出人体、参考物体、缝线与辅助对象。
- 指定导出分辨率（出图尺寸就是当前 3D 视口的尺寸）。
