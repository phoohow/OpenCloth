# 导出与工程

这篇讲工程如何保存与交付：工程文件的保存与恢复、版型与服装模型的导出格式、工艺单与排料图等交付物，以及与其他软件的协作方式。章节顺序依次为：工程的保存、打开、最近列表与自动保存（§1）、版型导入与导出（§2、§3）、服装模型与截图导出（§4、§5）、与其他软件协作的格式选择（§6）、常见问题与当前不支持的功能（§7、§8）、全流程回顾（§9）。

## 1. 工程文件（`.ocproj.json`）

OpenCloth 用 `.ocproj.json` 保存完整设计：版片几何、缝合关系与缝份、内部线与省道、刀口注释与尺寸标注、尺码表与放码数据、材质与物理参数（含四个贴图槽与平铺/偏移）、模特选择与体型尺寸、导入的模特与参考物体、光源与渲染设置（含环境贴图、光线追踪与降噪参数）。

> **说明**：它保存的是**设计与参数**，不是模拟后的网格。重新打开后布料回到初始形态，需要再按一次播放或自动着装（`Ctrl+D`）重新试穿。

> **注**：导入的模特模型、参考物体与环境贴图都以 data URL 内嵌进文件，换一台电脑可以直接打开，不需要重新导入，文件体积会明显增大。只含内置模特与随包环境图时文件很小，导入上述资源后保存与打开都会多花一点时间。

### 1.1 保存与打开

| 操作 | 方法 | 说明 |
| --- | --- | --- |
| 保存 | 【文件 → 保存】（`Ctrl+S`） | 浏览器下载一份【工程名.ocproj.json】。浏览器下载不会覆盖本地文件，多次保存就是多次下载，靠文件名区分版本 |
| 另存为 | `Ctrl+Shift+S` | 先询问工程名称（改名可撤销），再按新名字下载 |
| 打开 | 【文件 → 打开…】（`Ctrl+O`） | 选择 `.ocproj.json`，版型、缝合、材质、场景设置与内嵌的模特、参考物体一并恢复 |
| 新建 | `Ctrl+N` | 清空为空白工程：没有版片，模特也处于隐藏状态，需要先导入模特模型再开始制版。本机第一次打开（还没有任何快照）时才载入起步工程（女性模特与四张 T 恤版片） |

- 当前工程有未保存的改动时，新建与打开会先问【当前工程有未保存的修改，确定放弃吗？】。
- 打不开通常是必要字段缺失，界面会提示无效的工程文件。
- 缺失的可选字段（例如尺码表与生产标记）会按默认值补齐，不会报错。

### 1.2 最近打开

【文件 → 最近打开】列出最近在本机保存过的工程（最多 8 条，按时间倒序，显示名称与保存时间），点一条直接载入；底部【清除列表】清空这份记录。

> **注**：记录存在这台电脑的浏览器里，不包含在 `.ocproj.json` 文件中。换机器后需要重新打开一次工程。

### 1.3 自动保存

- 【文件 → 自动保存】选间隔：关闭 / 每 30 秒 / 每 1 分钟 / 每 5 分钟。**默认是每 1 分钟**，本机保存过选择时沿用该设置。
- 最多保留**最近 5 份**快照，超过后自动删掉最旧的一份；【文件 → 自动保存】子菜单按时间列出这些快照，点一条即恢复到那一份。
- 菜单栏右端常驻显示【自动保存 关闭】或【自动保存 60s · 最近一次快照时间】。
- 【立即保存快照】不用等间隔；没有快照时列表显示【暂无快照】。恢复后用【保存】或【另存为】保存为正式文件。
- 重新加载页面时自动恢复最近一份快照，刷新不会回到起步工程；新建工程也会立即写一份快照。自动保存设为【关闭】时不恢复。
- 快照只能在这台电脑的这台浏览器里找回；清浏览器数据会一并清掉。

## 2. 导入版型

【文件 → 导入】下有两个版型入口，导入以一步可撤销的操作替换当前版型（`Ctrl+Z` 可退回原版型）：

【DXF 版型…】：选一份 `.dxf`（R12 ASCII）。文件按毫米读入（1 单位 = 1 mm），按常见制版图层命名识别轮廓、缝份、布纹线、刀口、钻孔、内部线与文字注释图层：闭合轮廓生成版片，位于片内的小环成为内孔，识别到的标记转成对应的刀口与注释。找不到任何有效轮廓时会弹窗提示【DXF 导入失败：文件中未找到有效的版片轮廓】。

【JSON 版型…】：选一份 `.json`，这是给 AI / 外部工具生成版型用的交换格式，文件要求如下：

- 文件顶层的对象必须带 `points`、`edges`、`panels` 三个集合：点要有以厘米计的 `pos.x / pos.y`，边要有类型（直线 / 曲线 / 圆弧）与起止点引用，版片要有 `name` 与按顺序排好的 `outlineEdgeIds`。
- `darts`（省道）、`internalLines`（内部线）、`seams`（缝合）、`notches`（刀口）、`annotations`（注释）、`measurements`（尺寸标注）都可以一并给出。
- 字段写错或轮廓不闭合时，会弹窗列出**中文错误清单**，指明是哪个点、哪条边、哪片版型出了问题（如“边 edge-3 的 type「spline」无效”“AI 版型拓扑校验失败（前片）：版片「前片」的轮廓未闭合”），修好文件再导。

导入失败不会影响当前版型。

## 3. 导出版型

【文件 → 导出】子菜单里除了 3D 成品（§4、§5），还有六个制版出口，每项都会先打开一个选项对话框。下表是六个出口的选项一览，后面按格式展开：

| 条目 | 对话框【导出】按钮按下后 | 选项 |
| --- | --- | --- |
| DXF 版型… | 下载【工程名.dxf】 | 勾选**包含缝份轮廓**（默认勾上）：把每片的切割轮廓（外扩缝份后）写到缝份图层；**尺码范围**选【当前码】或【全部尺码（横向排开）】，选后者时多出**码间距(cm)**（默认 10）；**文本编码**选【UTF-8（中文原名）】或【ASCII（非 ASCII 转 \U+XXXX）】 |
| SVG 平面图… | 下载【工程名.svg】 | 同样有**包含缝份轮廓**勾选 |
| PDF 图纸… | 下载【工程名.pdf】 | **包含缝份轮廓**勾选、**纸张**（A4 / A3）、**输出方式**（适合单页 / 1:1 多页拼版）；适合单页时实时显示**输出比例**（约 1:N），多页时显示**预计页数**（如【2 × 3 页】）与**重叠(cm)** |
| 工艺单… | 下载【工程名-工艺单.pdf】 | 【面料幅宽(cm)】默认 150、【面料单价(元/m)】选填；缩率与片间距固定按 0 与 0.5 cm 计算 |
| 排料图… | 【导出格式】选 SVG 图片时下载【工程名-排料图.svg】，选 DXF 唛架时下载【工程名-排料图.dxf】；【导出 CSV 报告】下载【工程名-用料报告.csv】 | 【面料幅宽(cm)】默认 150、【缩率(%)】默认 0、【片间距(cm)】默认 0.5、【旋转角度】默认【0° / 90°】、尺码范围默认当前码、导出格式默认 SVG 图片、【面料单价(元/m)】选填；对话框实时显示版片数、用料长度、面料面积、利用率与面料成本 |
| 物料清单… | 先打开预览对话框，【导出 CSV】下载【工程名-物料清单.csv】 | 按类别／名称／规格／单位／数量／单价／金额／备注八列汇总面料、印花、明线与辅料 |

### 3.1 DXF

1 单位 = 1 毫米，Y 轴向上；按图层分别写入轮廓（含内孔）、缝份轮廓、内部线、布纹线、刀口与文字注释，可直接送切割机或打版软件。缝份图层写的是含逐边缝份的切割轮廓，与模拟和排料用的是同一条线。布纹线的位置与长度一并写入，重新导入时一并还原。

【全部尺码】：尺码范围选它时，按尺码表顺序（[02-版型设计](./02-版型设计.md) §8）把每一码各解一份几何，每个尺码的每片是一个独立块，块名后缀 `-码标`，各码沿 X 轴依次排开、组间留够**码间距**，彼此不会重叠；每片底下还会写一行码标文字，便于在 CAD 软件里辨认码号。选【当前码】时输出与单码完全一致。

【文本编码】：默认 UTF-8，片名与注释是原始中文。选 ASCII 时所有非 ASCII 字符写成 `\U+XXXX`（服装 CAD 常用的转义写法），整个文件只剩 ASCII 字节，读回来仍然还原成中文；超出基本平面的字符（emoji 一类）降级为 `?`。

### 3.2 SVG 平面图

1:1 厘米的矢量图，每张版片一个图层组（轮廓、缝份、内孔、内部线、省道、刀口、布纹线、注释），适合打印与插图。放码结果不进 SVG，它出的始终是当前码。

### 3.3 PDF 图纸

把所有可见版片写成 A4 或 A3 的矢量图纸，内容有净边或毛边、内部线、省道、刀口与布纹线，每片标 `P1`、`P2`…。

【输出方式】有两种：【适合单页】把全部版片排在一张纸上，装不下就整体缩小，页脚与对话框的输出比例（约 1:N）就是缩小后的真实比例；【1:1 多页拼版】按纸张可打印区域把整幅版型切成页面网格，每页只画落在这页范围内的部分，比例为 1:1。多页方式下对话框显示【预计页数】（如【2 × 3 页】，列 × 行）与【重叠(cm)】；相邻页保留这段重叠，拼贴时按页角十字标记对齐，轮廓跨页连续，页边还写页码、行号 / 列号、纸张与重叠量。

两种方式都下载【工程名.pdf】。

### 3.4 排料图

把所有**可见**版片各取一片，按含缝份的切割轮廓排进给定幅宽的面料里：

- 【缩率(%)】会先把每片按百分比放大再排（预缩补偿）。
- 【片间距(cm)】控制版片之间的间隔。
- 【旋转角度】可选 `0° / 90°`（默认）、`仅 0°`、`0°–90°，每 15°`、`0°–90°，每 5°`；不支持翻转（镜像）。

两种格式使用同一组位置：**SVG** 画在面料矩形边框内、1:1 厘米，片名写成文字并带上布纹线；**DXF 唛架** 把面料边界写在 0 层，每片轮廓写在轮廓层（`001-OUTLINE`）、布纹线写在 `031-GRAINLINE`、片名写在注释层，尺寸同样是 1 单位 = 1 毫米，可直接送裁床。

对话框在选项下方实时给出当前排料的**版片数**、**用料长度**、**面料面积**、**利用率**与（填了**面料单价**时的）**面料成本**。**导出 CSV 报告**把同一组数据按项目、数值两列写出，并附每个版片名称的数量与面积；文件开头带 UTF-8 BOM，Excel 直接打开中文不乱码。

**尺码范围**选【全部尺码】时，每一码各取一份切割轮廓一起排，片名后附码标，利用率与成本按全部尺码合计；选【当前码】时只排当前码。两种格式沿用【旋转角度】的设置，不含翻转。

没有可排片或幅宽填了无效值时，会弹出【请输入有效的面料幅宽(cm)】等提示。

### 3.5 工艺单

【文件 → 导出 → 工艺单…】生成多页 A4 PDF【工程名-工艺单.pdf】，内容全部从当前工程实时计算：

- 工程名、日期与尺码表：列出各码标，标出**基码**与当前码。
- 版片：每个可见版片的名称、数量、净面积(m²)与毛面积(m²)。
- 材质：每个材质的基础色、面密度(g/m²)、拉伸、弯曲、剪切、阻尼、折痕参数与贴图文件名。
- 缝合清单：甲 / 乙两片的名称与边、缝合区间、缝型、缝份与是否缩缝（含缩缝比例）。
- 印花：每片可见印花的名称、尺寸(cm)、角度、平铺与不透明度；没有时写【无印花】。
- 明线：所在边、偏移(mm)、行距(mm)、行数与长度（cm，区间长度 × 行数）；没有时写【无明线】。
- 辅料：名称、类型、直径(mm)、数量、单价与颜色；没有时写【无辅料】。
- 物料清单：与【物料清单…】对话框同一份数据，按类别／名称／规格／单位／数量／单价／金额七列列出，表后给出合计金额（只累加填了单价的行）。
- 排料摘要：按当前幅宽（默认 150 cm）、缩率 0、片间距 0.5 cm 排料，给出用料长度、面料面积、利用率与成本；没有可见版片时写【无可见版片，未排料】。
- 版片测量：所有能算出数值的尺寸标注。

对话框只保留【面料幅宽(cm)】与【面料单价(元/m)】两项：幅宽影响排料摘要，单价留空时不写成本。内容超出一页会自动分页，页脚带工程名与页码。

### 3.6 物料清单

【文件 → 导出 → 物料清单…】打开预览对话框，按当前工程实时汇总四类物料：

| 类别 | 数量口径 | 规格 |
| --- | --- | --- |
| 面料 | 各面料上可见版片的净面积之和(m²) | 面密度(g/m²)；未指定面料时单列一行 |
| 印花 | 平铺次数相乘后的张数 | 尺寸(cm)，平铺时附【平铺 a×b】 |
| 明线 | 区间长度 × 行数，换算成米 | 偏移(mm)、行数、行距(mm) |
| 辅料 | 标记的【数量】(个) | 类型与直径(mm) |

- 只统计可见版片与可见记录；隐藏的片或隐藏的印花、明线、辅料都不进清单。
- 金额只在填了单价时计算（单价 × 数量），没填的行金额留空、不参与合计；合计显示总金额与已定价行数。
- **导出 CSV** 下载【工程名-物料清单.csv】，列为类别、名称、规格、单位、数量、单价、金额、备注（备注写所属版片），带 UTF-8 BOM 与 CRLF 换行，Excel 直接打开中文不乱码。
- 工程里没有可见物料时对话框给出提示，导出按钮不可用。

## 4. 导出 3D 模型

导出的是**当前模拟状态下的布料快照**，入口在【文件 → 导出】子菜单。

### 4.1 GLB 与 OBJ

**服装 GLB…** 下载【工程名.glb】，包含布料网格的顶点、面、UV、法线与 PBR 材质参数（基础色、粗糙度、金属度、光泽等），四个贴图槽的贴图内嵌进文件；带印花的片导出的是合成后的基础色贴图。**服装 OBJ…** 下载【工程名.obj】，只有顶点、法线与面索引，**不生成 MTL 材质文件**；需要材质就用 GLB。

### 4.2 包含与不包含的数据

| 数据 | GLB | OBJ |
| --- | --- | --- |
| 布料网格顶点 / 面 | 是 | 是 |
| UV 坐标 | 是 | 否 |
| 法线 | 是 | 是 |
| 材质参数 | 是 | 否 |
| 面料贴图 | 是（内嵌） | 否 |
| 印花图案 | 是（已合成进基础色贴图） | 否 |
| 明线、辅料符号 | 不含 | 不含 |
| 模特、参考物体 | 不含 | 不含 |
| 选中高亮、PIN 小球、缝纫线 | 不含 | 不含 |

> **注**：GLB 按布料**当前指定的材质**导出；线框、UV 检查和法线可视化会替换视口材质，想拿标准 PBR 成品就先切回【光栅化】或【光线追踪】。

## 5. 导出图片

【文件 → 导出 → 导出截图 PNG】，按当前 3D 视口分辨率下载【工程名.png】。画面里只有 3D 内容（服装、模特、地面、环境），不含任何界面元素。

- 选择【光线追踪】时，画面在动（拖动相机、播放模拟）导出到的是光栅帧，静止后才是渐进采样结果；建议在暂停且画面收敛后再导出（开了降噪就等它降噪完成、画面不再变化时导出）。
- 需要换构图或分辨率时，先用鼠标调整 3D 视口（或按 `1` 切到仅 3D 视口放大）再导出。
- 连续画面用下面的**导出动画 WebM…**；需要逐帧控制时也可以逐帧单步（`.`）后分别导出截图，或导出 GLB 后在外部软件里渲染。

【文件 → 导出 → 导出动画 WebM…】，录制当前 3D 视口 5 秒（帧率(fps) 30）并下载【工程名.webm】。同样只录 3D 内容，不含界面；选择【光线追踪】时录制到的是光栅帧；浏览器不支持画布录制时会给出提示。

## 6. 与其他软件协作

| 目标软件 | 推荐格式 | 说明 |
| --- | --- | --- |
| 切割机 / 打版软件 | DXF | 毫米图层文件，含缝份与否由导出选项决定 |
| Blender | GLB | 直接导入，保留材质参数与内嵌贴图 |
| Unity / Unreal | GLB | 可直接导入，或按插件需要转成 FBX |
| CLO3D / Marvelous Designer | OBJ | 作为参考网格导入 |
| 网页展示 | GLB | three.js / `<model-viewer>` 原生支持 |

## 7. 常见问题

**Q：导出的网格面数太高？**
A：在工程标签把【网格边长】调大（例如 2–3 cm），布料密度随之下降，重新模拟后再导出。

**Q：昨天做的工程今天找不到了？**
A：【文件 → 最近打开】与自动保存快照都只记录在本机浏览器里。自动保存默认每 1 分钟写一份快照并保留最近 5 份，可以先用它找回；长期保存仍建议用 `Ctrl+S` 下载 `.ocproj.json`。

**Q：DXF 导入后版片不完整，或提示未找到有效轮廓？**
A：只有**闭合**轮廓会成为版片，未闭合的线段与无法识别的图层会被忽略；确认导出端按毫米作图、图层命名可识别。

## 8. 当前不支持

- 直接覆盖本地文件（浏览器下载模型每次都是新文件）。
- 旧版本工程文件的读取与迁移。
- 导出模特、参考物体、缝纫线与辅助对象。
- 指定导出分辨率（出图尺寸就是当前 3D 视口的尺寸）。
- 排料不支持翻转（镜像）；旋转角度为对话框提供的四档，不提供任意角度的自由输入。

## 9. 全流程回顾

OpenCloth 的服装设计与制作流程由以下五步组成：

1. [版型设计](./02-版型设计.md)：用模板、导入或绘图工具做出 2D 版型
2. [缝合与着装](./03-缝合与着装.md)：缝合配对并穿到模特上
3. [布料模拟](./04-布料模拟.md)：调面料与环境参数得到自然褶皱
4. [材质与渲染](./05-材质与渲染.md)：赋予真实感面料外观与布光
5. 导出与工程：出 DXF / SVG / PDF / 工艺单 / 排料图，保存与分享作品
