# 版型系统

这篇讲 2D 图纸如何变成可模拟、可穿在身上的布料网格：曲线与圆弧怎么采样、轮廓怎么外扩缝份、多边形怎么变成带镂空的均匀三角形、整套版型怎么由模板生成，平面片按什么规则贴合到模特上，以及放码、排料与自动缝合建议。代码在 `src/pattern/`，提交前的拓扑校验在 `src/core/model/`。

从图纸到网格的顺序固定：`Pattern` 里的点、边、省道与内部线经轮廓采样、缝份偏移、三角化与保形细化得到每张片的 `PanelMesh`；模板生成整套版型，解析摆放把平面片贴合到模特上，最后由脱体与缝合目标交给模拟层。

章节顺序依次为：几何内核（§1）、三角化与细化（§2）、版片构建器（§3）、参数化模板（§4）、环绕落片（§5）、脱体与缝合目标（§6）、放码与排料（§7）、版型导出（§8）。

## 1. 几何内核

内核只处理平面几何：向量运算与绕序约定、贝塞尔与圆弧的自适应采样与弧长参数、整条轮廓的缝份外扩、外扩自交时的回退路径、圆角与轮廓重构，以及命令提交前的拓扑校验。

### 1.1 向量与绕序

类型与构造器（`Vec2` / `vec2()`）在 `core/model/types.ts`；`pattern/geom/vec2.ts` 是围绕它们的纯函数集合，`cross` 与 `length` 是文件内私有辅助，对外导出：

```typescript
export const add / sub / scale / dot / distance / normalize / lerp
/** 顺时针法线：(x, y) → (y, −x)。 */
export const perp = (v: Vec2): Vec2 => ({ x: v.y, y: -v.x });
export function polygonArea(poly: Vec2[]): number;
export function ensureCCW(poly: Vec2[]): Vec2[];
export function computeBBox(points: Vec2[]): { min: Vec2; max: Vec2 };
```

`ensureCCW` 在偏移与三角化之前统一绕序，`perp` 的符号约定因此成立：逆时针多边形的 `perp(边向量)` 指向外侧；这条约定贯穿缝份偏移与 3D 正面朝向（03 §2.3）。

### 1.2 曲线、圆弧与弧长参数

轮廓的曲线段是三次贝塞尔，四个控制点是边的两个端点加两端点上的 `handleOut` / `handleIn`（绝对制版坐标，02 §4.1）；圆弧段是 `ArcGeom`（圆心、半径、起止角与走向，02 §4.2）。

#### 1.2.1 三次贝塞尔

`pattern/geom/bezier.ts`：

```typescript
export interface CubicBezier2 { p0: Vec2; c0: Vec2; c1: Vec2; p1: Vec2; }
/** 德卡斯特里奥求值。 */
export function evalBezier(b: CubicBezier2, t: number): Vec2;
/** 在 t 处一分为二，两段的并集覆盖原曲线。 */
export function splitBezier(b: CubicBezier2, t: number): [CubicBezier2, CubicBezier2];
/** 递归细分到曲线中点与弦中点的偏差进容差内。 */
export function adaptiveSampleBezier(b: CubicBezier2, tolerance = 0.1, maxDepth = 8): Vec2[];
/** 由两端点的控制柄拼出完整三次形式；smooth 点缺一个控制柄时按另一个关于点镜像。 */
export function edgeCurve(pattern: Pattern, edge: PatternEdge): CubicBezier2 | null;
/** 把两个控制点写回边的两端点，并把两点置为 smooth。 */
export function setEdgeCurve(pattern: Pattern, edge: PatternEdge, c0: Vec2, c1: Vec2): void;
/** 在 at 处分裂一条曲线边：三个点各得控制柄，两条同 semantic 的 bezier 边。 */
export function splitEdgeCurve(
  pattern: Pattern, edge: PatternEdge, at: Vec2,
  makeEdge: (startId: string, endId: string) => PatternEdge,
): [PatternEdge, PatternEdge];
/** 离给定点最近的曲线参数（32 次采样取最优）。 */
export function curveTForPoint(curve: CubicBezier2, p: Vec2): number;
```

采样密度由偏差容差决定，而不是曲率：

```
subdivide(b, tol, out, depth, maxDepth):
  mid = evalBezier(b, 0.5);  chord = lerp(b.p0, b.p1, 0.5)
  if distance(mid, chord) < tol or depth == maxDepth: out.push(b.p1); return
  [left, right] = splitBezier(b, 0.5)
  subdivide(left, …); subdivide(right, …)
```

起点先入列、之后每次只追加终点，因此相邻子段不会重复顶点；没有控制柄的 `bezier` 边 `edgeCurve()` 返回 null，按直线画。

#### 1.2.2 圆弧与刚体变换

圆弧在 `pattern/geom/arc.ts`，全部围绕 `ArcGeom` 的圆心式参数：

```typescript
/** 弧的带符号扫角（弧度），顺时针为负。 */
export function arcSpan(arc: ArcGeom): number;
/** 扫角分数 t 处的点。 */
export function evalArc(arc: ArcGeom, t: number): Vec2;
/** 三点定弧，共线返回 null；走向跟随 a → mid → b 的顺序。 */
export function arcFromThreePoints(a: Vec2, mid: Vec2, b: Vec2): ArcGeom | null;
/** 按弦高容差定步数采样，最少 8 段。 */
export function adaptiveSampleArc(arc: ArcGeom, tolerance = 0.02): Vec2[];
```

弧始终连接它的两个端点，由 `core/command/patternMoveGeometry.ts` 的 `refitArcs(pattern, movedIds, options, records?)` 统一维护：

- **两端同向平移**：按刚体处理，`center` 加上位移，半径与起止角不变。
- **只有一端移动**：用【新端点 + 弧的中点】重解 `arcFromThreePoints`；中点位置由 `options.midpoint` 决定（平移默认原地不动，改夹角时绕共享顶点同角度转）。
- **三点共线**：该边退回 `type:'line'` 并删掉 `arc`。
- **数值编辑**：`SetArcParamsCommand(edgeId, { radiusCm } | { sweepDeg })`（`patternAdvancedCommands.ts`）保持两端点与 `ccw` 不变，圆心在弦的垂直平分线上重新求出。只给半径时沿用原圆心所在的一侧，只给圆心角时按扫掠方向与大小选侧，因此正向/反向弧不会互换。半径小于弦长一半时夹到半圆，`radiusCm <= 0`、`sweepDeg` 不在 0°~360° 之间或两者同时给出都抛错。

采样、三角化、缝份外扩与导出因此不会看到脱开轮廓的弧。§7.1 的切码在 `resolveSize()` 里按同一规则重解（码档差不同时中点随两端档差的均值走）。

#### 1.2.3 边采样与弧长

`pattern/geom/edgeSample.ts` 把两种曲线收敛成一条边的折线与弧长参数：

```typescript
export function sampleEdge(pattern: Pattern, edgeId: string, reverse?: boolean): Vec2[];
/** 弧长分数 t 处的点；t 先夹到 0~1。 */
export function pointAtT(pattern: Pattern, edgeId: string, t: number): Vec2 | null;
/** 弧长子区间 [t0, t1] 的采样折线，两端用 pointAtT 补齐。 */
export function sampleEdgeInterval(
  pattern: Pattern, edgeId: string, t0 = 0, t1 = 1, reverse?: boolean,
): Vec2[];
/** 一条边采样后的总弦长，单位 cm。 */
export function edgeLength(pattern: Pattern, edgeId: string): number;
/** 一条尺寸标注的读值：距离与边长为 cm、角度为度；引用缺失返回 null。 */
export function measurementValue(pattern: Pattern, measurement: Measurement): number | null;
```

- `sampleEdge` 的分派：`arc` 用 `adaptiveSampleArc(arc, 0.02)`、`bezier` 用 `adaptiveSampleBezier(curve, 0.2)`、直线返回两个端点；`reverse` 返回拷贝后的反序数组，缝合的乙边靠它取向。
- 弧长一律用采样折线的弦长累加（文件内私有 `chordLengths()`），因此 `pointAtT` 与 `edgeLength` 的误差就是采样误差。
- `measurementValue()` 的三种 `kind`：`distance` 取两点 `hypot`、`edgeLength` 取 `edgeLength()`、`angle` 取 `atan2` 的度数；2D 尺寸线标签、属性面板的当前值与各码数值表都调用它。

> **注**：没有 `sampleBezier(b, segments)` 这类等参步采样：参数 `t` 是形状参数，弧长位置要走 `pointAtT()` / `sampleEdgeInterval()`。离线预览 `src/tools/clothPreview.ts` 仍自带私有 `polylineLength()`，没有复用 `edgeLength()`。

### 1.3 缝份偏移

缝份把整条采样后的轮廓折线向外偏移 `Panel.seamAllowanceCm`，得到的多边形直接作为三角化输入。算法是带尖角限幅的角平分线（miter）偏移（`pattern/geom/offset.ts`）：

```
offsetPolygon(polygon, dist)：
  n < 3 → 原样拷贝返回
  对每个顶点 i（取模自动首尾相接）：
    n1 = normalize(perp(curr − prev));  n2 = normalize(perp(next − curr))
    bisector = normalize(n1 + n2)       // 两法线完全反向（180° 折返）时退回 n1
    miterLen = dist / dot(bisector, n1)                       // = dist / cos(θ/2)
    miterLen = sign(miterLen) × min(|miterLen|, |dist| × 4)   // 尖角限幅，防长刺
    result.push(curr + bisector × miterLen)
```

#### 1.3.1 多边形偏移

正值外扩逆时针多边形，负值内缩。同文件另有折线版本 `offsetPolyline(points, dist)` 与逐点单位法线 `computePolylineNormals(points)`；后者被 `OutlineSplitCommand` 拿来把切割折线扩成一条细窄闭环（私有 `cutBand`），前者除单元测试外只被尚未接入界面的进阶命令引用（06 §3.2 的注）。

#### 1.3.2 逐边缝份与角型

逐边缝份不在 `offsetPolygon` 里，而在 `panelBuilder.ts` 的 `panelOutlineWithAllowance()`：

- **快速路径**：整片所有边同值且角型都是 `miter` 时，直接走 `safeOffsetPolygon`。
- **逐边分配**：否则按每条边的 `seamAllowanceCm` 覆盖值与 `cornerStyle` 逐点分配，一个采样点属于【终结在它那条边】的角，因此角上的接法跟着到达它的那条边，再交给 `offsetPolygonStyled()`。`miter` 用角平分线夹到 4 倍、`round` 在凸角按 15° 一段补圆弧、`bevel` 直接斜切；两侧缝份量不等时用 `offsetLineJoin()` 求两条偏移线的真交点。
- **回退**：结果自交时退回 `offsetOutlinePerEdge()`（逐边法线外扩，相邻两段的偏移结果直线相接）。
- **唯一来源**：模拟网格、2D 的【缝份线】图层、SVG 平面图的缝份层、DXF 的 `002-SEAMLNE` 层、PDF 图纸和唛架排料都调它，所以净边／毛边在界面上只是 `displayOptions.seamAllowance` 一个开关，导出数据不会各画各的。

> **注**：缝份参与模拟网格，不是一条独立的显示线；改动偏移算法会同时改变模拟粒子分布（02 §4.4）。2D 的【缝份线】图层画的是另一条虚线，只在 `panel.seamAllowanceCm > 0` 或有边级覆盖时出现。

### 1.4 自交检测与安全偏移

内偏移或尖角密集处可能自交，检测是 O(n²) 的两两线段相交（跳过相邻边与首尾相接那一对，顶点少于 4 直接返回 false）：

```typescript
export function hasSelfIntersection(polygon: Vec2[]): boolean;
/** miter 结果自交时，退化为逐点沿前后点连线的法线偏移。 */
export function safeOffsetPolygon(polygon: Vec2[], dist: number): Vec2[];
```

- `buildPanelMesh()` 用的就是 `safeOffsetPolygon`。
- 回退路径不做 miter 修正，因此不会自交，但角部尺寸偏小。
- 没有扫描线加速，也不裁掉自交环。
- `hasSelfIntersection` 还被 `OutlineHoleCommand`（内孔环不许自交）与 `validateGrading()`（每码轮廓检查）复用。

### 1.5 圆角与轮廓重构

#### 1.5.1 几何：切弧与切点

`pattern/geom/fillet.ts` 把轮廓上的一个角替换成切弧：

```typescript
export interface FilletResult {
  /** 替换后的三条边：内边修剪段、切弧、外边修剪段，按轮廓顺序。 */
  edges: PatternEdge[];
  newPointIds: string[];
}
/** 用一个角相邻两条边上的切点插入切弧，登记新点与新边并删掉被替换的两条边。 */
export function filletCorner(
  pattern: Pattern, pointId: string, radius: number,
  makeEdge: (startId: string, endId: string) => PatternEdge,
): FilletResult | null;
/** 逐个倒角，后一个能看到前一个已经改好的边；任一角失败即返回 null。 */
export function filletCorners(
  pattern: Pattern, pointIds: string[], radius: number,
  makeEdge: (startId: string, endId: string) => PatternEdge,
): FilletResult | null;
```

- 直线-直线角得到精确切点；相邻边是曲线或圆弧时按采样折线末段的方向近似切线，切点用弧长定位（`cutPoint()`，圆弧按角度、曲线按弦长累加）。
- 半径超出相邻边长、角是尖点或平角时返回 null，`FilletCornersCommand` 把它们变成中文错误【圆角半径过大，超出相邻边长】【圆角需要相邻的两条轮廓边】。
- 替换后保留原边的 `semantic`、`seamAllowanceCm` 与 `cornerStyle`。

#### 1.5.2 命令：接回轮廓与迁移缝合

命令侧的整套重构在 `core/command/patternEditCommands.ts`：

```typescript
/** 一个被圆角替换掉的角：删掉的两条边（含原长）与补上的三条边（含新长）。 */
export interface FilletChange { cornerPointId: string;
  removed: Array<{ edgeId: string; lengthCm: number; side: 'in' | 'out' }>;
  added: Array<{ edgeId: string; lengthCm: number }>; }
/** 逐个倒角、把新边接回轮廓与内孔环、迁移缝合区间，最后清理孤立点与边。 */
export function applyFillets(pattern: Pattern, pointIds: string[], radiusCm: number): FilletChange[];
```

- 轮廓与孔环是**环**，被替换的相邻两边可能正好跨过数组首尾，`spliceChain()` 因此先把环旋转到该链再拼接。
- `remapSeamsAfterFillet()` 按长度比例把落在被切掉那段上的缝合区间挪到剩下的边上（内侧 `t / share`、外侧 `(t - cut) / share`，`anchorT` 同样换算）；区间整段落在被切掉的部分时删除该缝合。
- 收尾调用 `prunePattern()`：角点被两条边一起替换后不再被任何边引用，留着会被 §1.6 判成 `orphan_point`。

#### 1.5.3 布尔与成环工具

多边形层面的布尔与成环工具分两处：

`pattern/geom/polygonBoolean.ts` 提供 `unionPolygons` / `intersectPolygons` / `differencePolygons` / `selfIntersectFix`，基于 `polygon-clipping`，结果外环逆时针、孔环顺时针。

`pattern/geom/toPatternLoop.ts` 的 `polygonToEdgeLoop()` 把闭合折线登记为点与直线边，可按 `mergeScope: 'panel' | 'pattern'` 合并重合点、按 `winding: 'cw'` 生成孔环。

这两处的公开函数目前还没有调用方，作为几何内核的预留接口保留；`OutlineSplitCommand` 与 `MergePanelsCommand` 直接引入 `polygon-clipping` 的 `union` / `difference`。

### 1.6 拓扑校验

#### 1.6.1 入口与索引

一次提交必须满足的不变量集中在 `core/model/validatePattern.ts`；索引结构在 `core/model/patternGraph.ts` 的 `buildPatternGraph()`：

- `edgeLocations`：edgeId → 各版片轮廓与内孔的位置。
- `outline`：panelId → 有序轮廓位置。
- `pointRefs`：pointId → 引用它的边端点。

```typescript
export function validatePattern(pattern: Pattern, options: ValidateOptions = {}): PatternIssue[];
/** 缝合某一侧沿其边的区间，缺省整边 [0, 1]。 */
export function seamInterval(seam: Seam, side: 'a' | 'b'): readonly [number, number];
```

```typescript
// pattern/seam/seamWarnings.ts
export function seamWarnings(pattern: Pattern): PatternIssue[];
```

`PatternIssue` 带 `code`、`targetId` 与中文 `message`；`SnapshotCommand` 在 `execute()` 里用 `assertValidPattern()` 取第一条错误抛出，2D 工具条的【检查】菜单列出全部问题、点一条即选中那一处。

`validatePattern()` 只报拓扑错误，不 import 版型层的任何东西（`core/model → 无`，见 [01-架构总览](./01-架构总览.md) §1.1）。

需要按弧长量出的缝合提示住在 `pattern/seam/seamWarnings.ts`，它复用 `seamInterval()` 与 `edgeIntervalLength()`，产出的 `PatternIssue` 一律带 `severity: 'warning'`，因此不参与提交门禁，只进【检查】菜单。

| `code` | 检查什么 | `targetId` |

`seamWarnings()` 的两条提示（`severity: 'warning'`，不阻断提交）：

| `code` | 提示什么 | `targetId` |
| --- | --- | --- |
| `seam_length_mismatch` | 缝合两侧**被缝的那一段**采样弧长差超过 0.3 cm 且超过较长一侧的 2%（两个门槛都要过才报）；缩缝（`type: 'gather'`）、带 `gatherRatio` 的缝合、以及同一省道两条腿之间的缝合都不报 | 缝合 id |

- `ValidateOptions.allowOpen` 是绘稿豁免：为真时 `orphan_edge` / `orphan_point` 两条归属检查放过挂在有效边上的点与尚未进入任何闭合轮廓的边。当前所有调用方都用默认的 `false`（`assertValidPattern()`、DXF 导入、`aiContract`、检查菜单），因此画到一半的折线不会进工程，也不存在以 `allowOpen: true` 提交的入口。
- 内孔环的边也进 `edgeLocations`，因此镂空环自身就满足归属检查；但闭合、长度与重复检查只遍历 `outlineEdgeIds`，孔环只要求采样点数 ≥ 3（`buildPanelMesh()` 过滤）。
- `seam_overlap` 在同一边的区间排序后一旦重叠即报告一次并停止。

### 1.7 曲线重拟（pattern/geom/polyCurve.ts）

`SimplifyCurveCommand`（06 §3.2 的进阶命令表）用的最小二乘拟合在这里：端点与两端走向固定，只解两个控制柄长度，所以拼接处的切线连续性不会被拟出来破坏。

```typescript
export interface BezierFitInput {
  samples: Vec2[];            // 拟合跟随的密采样，含两端
  start: Vec2; end: Vec2;     // 固定的段端点
  startTangent: Vec2; endTangent: Vec2; // 固定的单位走向
}
export interface HandleLengths { start: number; end: number }
/** 按弦长参数化解两端控制柄长度；样本不足 2 个时返回全 0。 */
export function fitBezierHandles(input: BezierFitInput): HandleLengths;
/** 用解出的柄长拼出那条三次曲线。 */
export function bezierFromFit(input: BezierFitInput, handles: HandleLengths): CubicBezier2;
/** 采样点到圆弧的最大偏差(cm)。 */
export function deviationFromArc(arc: ArcGeom, points: Vec2[]): number;
/** 两条折线之间的最大点距(cm)，用于验收【容差内】这条判定。 */
export function maxDistanceToPolyline(points: Vec2[], polyline: Vec2[]): number;
/** 一个点到折线的最近距离(cm)。 */
export function distanceToPolyline(p: Vec2, polyline: Vec2[]): number;
```

单边简化先看能不能降成一段圆弧（`deviationFromArc` 在容差内即可），否则退化成直线，再否则按三次曲线重拟；链简化把相邻若干段合成一条三次曲线，控制柄写回两端锚点（`handleOut` / `handleIn`），中间锚点与其边被删掉，减不出边数时命令抛中文错误而不是硬拟合。

### 1.8 接角圆顺（pattern/seam/joinBlend.ts）

一条缝合的两个端点各是一个接角：两片布缝合后在端点处围出的材料角，预览拼接形状与调整圆顺都以这个角为判据。

```typescript
export type SeamJointEnd = 'start' | 'end';
/** 把乙片刚体变换进甲片坐标的映射（厘米）。 */
export type SewnPose = (p: Vec2) => Vec2;
export interface SeamJoint {
  seamId: string; end: SeamJointEnd;
  panelAId: string; panelBId: string; pointAId: string; pointBId: string;
  pos: Vec2;                 // 接角在甲片坐标里的位置
  angleDeg: number;          // 缝合后从接角伸出的两条轮廓边之间的夹角，180 为顺直
  bendDeg: number;           // 180 - angleDeg：这里折了多少
  overlap: boolean;          // 接角附近两片互相压住
  pose: SewnPose;
}
/** 缝合两端必须停在轮廓角点上，否则返回 null。 */
export function seamJoint(pattern: Pattern, seamId: string, end: SeamJointEnd): SeamJoint | null;
/** 乙片轮廓按 pose 画进甲片坐标，即缝合后的样子。 */
export function sewnOutline(pattern: Pattern, joint: SeamJoint): Vec2[];
/** 需要倒圆的两个角点（甲片、乙片各一个）。 */
export function jointCornerIds(joint: SeamJoint): string[];
```

- 夹角量的是**缝合后从接角伸出去的两条轮廓边**之间的张角：两片各自的角相等时两条边成一直线（180°，顺直），不相等就折。方片接方片得 180°，方片（90°）接等边三角片（60°）得 150°、`bendDeg` 30°。
- `pose` 只旋转加平移（不镜像）：把乙片缝合边的走向转到甲片走向的反向，两片布料因此分居缝纫线两侧，正是拷边后压平的状态；`flip` 决定乙片用区间哪一端配对（`flip` 为真时甲 `t0` 配乙 `t1`）。
- `overlap` 只在看接角周围 `JOINT_PROBE_CM`（2 cm）半径内的轮廓采样：某点落在对方轮廓内、且离对方所有采样点都超过 `PENETRATION_CM`（0.4 cm，避开采样噪声）才算压住。起始 T 恤模板的侧缝读数 0°～8.7° 弯折、肩缝与袖窿 11.8°～57.9°。
- 角点位置按坐标匹配采样折线的顶点（容差 1e-4 cm），因此曲线边接曲线边同样能量化。
- `BlendSeamJointCommand`（06 §3.2）把 `jointCornerIds()` 的两个角交给 `applyFillets()`，一次撤销全退。

## 2. 三角化与细化

轮廓闭合之后需要两步才成为模拟网格：先由 earcut 得到三角形（§2.1），再把过长的边分裂到接近目标边长（§2.2）。

### 2.1 earcut 集成

```typescript
// pattern/triangulate/triangulate.ts
export interface TriangleMesh {
  positions: Float32Array;   // flat [x0,y0,…]，制版坐标(cm)
  indices: Uint32Array;      // 三角形索引
  vertexCount: number;
  triangleCount: number;
}
/** 闭合多边形三角化，可带洞。 */
export function triangulatePolygon(outline: Vec2[], holes: Vec2[][] = []): TriangleMesh;
```

- 返回值就是 `TriangleMesh`，没有单独的包装类型。
- `holes` 由 `buildPanelMesh()` 传入：每个 `Panel.holes` 环经 `sampleOutline()` 采样、丢掉少于 3 点的环后作为耳剪输入，镂空因此进入模拟网格而不是只显示。
- 省道与内部线不改变三角化的输入轮廓；`Dart` 与 `InternalLine` 记录由命令维护（02 §4.3），2D 各自成层绘制。
- 同文件还提供 `buildAdjacency`（相邻三角形对，弯曲约束的来源）与 `extractBoundaryEdges`（只被一个三角形使用的边）。

### 2.2 保形细化

三角化的边长不均匀，模拟粒子密度需要接近目标边长。`refineMesh(mesh, targetEdgeLength, maxIterations = 24)` 用 conforming 最长边分裂，再做平滑与合法化：

```
中点缓存 midpointCache 跨所有轮次 → 同一根边永远复用同一个中点顶点
每轮先做一遍 Delaunay 翻转（只翻短于 targetEdgeLength × 1.4 的新对角线），
再逐三角形找最长边，只对超过该阈值的边登记分裂：
  0 条 原样保留
  1 条 二分
  2 条 共用顶点处的角三角形 + 另外两块
  3 条 red refinement，切成四个全等三角形
没有新分裂即结束
最后的平滑阶段交替执行 8 遍内部顶点向邻域质心松弛与 2 遍翻转
```

- 每轮只分裂**最长边**而不是全部超长边，否则边界上的短边会触发 red refinement 的指数增长（前片约 4.1k 顶点）。
- 翻转只在新对角线不超阈值时进行，因此不会把网格换成细长条，也不会把面积较大的三角形翻成超长的。
- 平滑只移动内部顶点：边界顶点的位置决定轮廓，轮廓不动，内部趋向正三角形。每次移动前校验三个相邻三角形的面积不小于原来的 0.4 倍且符号不变，所以不会翻面。
- 因为共享边复用同一个中点，网格在 3D 大变形下不会开裂。
- 轮廓边同样参与分裂（不排斥边界），边界粒子密度与内部一致，缝合约束才能按弧长比例配对。
- 细化后测得的边长中位数在 1.0–1.5 cm 区间，角度小于 10° 的三角形基本消失（`test/pattern/triangulate` 覆盖）。

### 2.3 轮廓重采样

细化之前，`resampleClosedOutline(points, spacing)` 把采样后的轮廓按弧长重排成近似等距的顶点（`CORNER_ANGLE_RAD = 50°` 以上的转角逐点保留原位置）。曲线边的采样间距与直线边的端点间距相差数倍。重采样之后耳剪看到的是尺寸统一的边界顶点，细化只需处理边长。

`buildPanelMesh()` 对整片轮廓与每个内孔环都走这套重采样；最后一个链段回到首角点时会重复落点，那里会丢掉重复的收尾顶点。

## 3. 版片构建器

### 3.1 接口与流水线

`PanelBuilder` 是一组纯函数，不是类（`pattern/panel/panelBuilder.ts`），把一张片的七类数据一次算齐；轮廓既可由模板生成（§4），也可在 2D 视口用矩形 / 圆 / 椭圆 / 自由折线工具画出来（06 §4.4）。

```typescript
export interface PanelMesh {
  panelId: string;
  positions2D: Float32Array;    // 细化后的制版坐标（flat x,y），UV 与 3D 位置的来源
  positions3D: Float32Array;    // 同点位形，cm→m、z=0
  indices: Uint32Array;
  uvs: Float32Array;
  vertexCount: number;
  triangleCount: number;
  boundaryEdges: Array<[number, number]>;   // 轮廓边顶点对
  edgeVertexMap: Map<string, number[]>;     // edgeId → 该边采样顶点的粒子索引
}

/** 制版坐标采样 → 缝份外扩 → 三角化（带内孔）→ 细化 → UV → 3D 位置 → 缝合边映射。 */
export function buildPanelMesh(pattern: Pattern, panelId: string, resolutionCm?: number): PanelMesh | null
/** 整片轮廓（含缝份前）与单个内孔环的采样折线。 */
export function samplePanelOutline(pattern: Pattern, panel: Panel): Vec2[]
export function sampleOutline(pattern: Pattern, edgeIds: string[]): Vec2[]
/** 把 PanelMesh 当作普通 2D 三角网格看，约束构建器读的形式。 */
export function toTriangleMesh(mesh: PanelMesh): TriangleMesh
/** 一条边（可按 spacingCm 重采样）映射到最近的网格顶点序列。 */
export function edgeVertexRun(
  pattern: Pattern, edgeId: string, mesh: TriangleMesh, spacingCm?: number,
): number[]
/** 网格三角形边长的中位数，单位 cm。 */
export function meshSpacingCm(mesh: TriangleMesh): number
// 再导出几何内核：sampleEdge / sampleEdgeInterval / pointAtT / edgeLength
```

流水线：

```
panelOutlineWithAllowance(§1.3：samplePanelOutline → 统一缝份走 safeOffsetPolygon，
                                     逐边覆盖走逐点法线外扩)
  → 轮廓与每个内孔环各走一遍 resampleClosedOutline(§2.3)，按弧长等距重排
  → 顶点少于 3 → 返回 null（该片不进模拟）
  → triangulatePolygon(外扩轮廓, 内孔环) → refineMesh(resolutionCm ?? panel.meshResolutionCm)
  → generateUVs(mesh.positions, computeBBox(外扩后的轮廓))
  → to3D(× 0.01，z = 0)
  → extractBoundaryEdges → buildEdgeVertexMap
```

两个要点：

网格边长的归属规则：`Panel.meshResolutionCm` 是该片的有效值，引擎在 `buildCloth()` 与按片增量重建的 `syncFromProject()` 里不传第三个参数，由 `buildPanelMesh()` 读取片字段。离线预览仍按档位传入粗网格。

`SetGlobalMeshResolutionCommand` 把同一值写进全部版片并同步 `SimulationConfig.meshResolutionCm`，只作为最近一次批量设置的记录；`positions3D` 只是 z=0 的平面位形，真正的着装姿态由 `InitialPose` / `MergedCloth` 负责（04 §5.1），约束静止长度也从那里量出。

### 3.2 缝合边映射

`buildEdgeVertexMap()` 遍历 `panel.outlineEdgeIds` 与展开后的 `panel.holes` 边，把每条边的采样点吸附到最近的边界顶点（候选集来自 `boundaryEdges`），相邻重复索引会被去掉。

- 采样点吸附到最近的网格顶点：缝份把网格边界外移过，采样点不在网格上。
- 吸附之后有缝份的版片仍能生成缝合约束（04 §1.3.3 按这个映射取粒子对）。
- 缝合区间（`SeamEnd.t0/t1`）在两侧各自换算：2D 用 `sampleEdgeInterval()` 画出被缝的那一段，求解侧 `core/engine/mergedCloth.ts` 的私有 `intervalVertices()` 在 `edgeVertexMap` 的顶点序列上按弧长分数截取（04 §1.3.3），`anchorT` 再把它折成两段配对。
- `edgeVertexRun()` 与 `meshSpacingCm()` 面向【按边取一段连续粒子】这类需求：前者把一条边（可按给定间距重采样）映射到最近的网格顶点序列，后者给出该片三角形边长的中位数作为间距。

### 3.3 UV 生成

UV 把制版坐标按该片包围盒归一化，让贴图与版型自然对齐。函数是 `panelBuilder.ts` 内的私有 `generateUVs(positions2D, bbox)`，包围盒由调用方用 `computeBBox(偏移后的轮廓)` 先算好，宽高为 0 时按 1 处理防除零：

```typescript
uvs[i*2]     = (positions2D[i*2]     - bbox.min.x) / (bbox.max.x - bbox.min.x || 1);
uvs[i*2 + 1] = (positions2D[i*2 + 1] - bbox.min.y) / (bbox.max.y - bbox.min.y || 1);
```

- UV 随网格合并成整件服装的一份（`mergedUVs()`），此后静态不变。
- 印花合成贴图按同一份 UV 方格摆放图案：`panelPrintFrame()` 用**网格包围盒**（含缝份）作为 UV 框、用**净轮廓包围盒中心**作为摆放原点，`printPlacement()` 再把 `Print` 的矩形、偏移与平铺换算成 UV 比例（03 §3.7）。两者取不同的包围盒，所以图案位置在加缝份前后保持一致。
- 织物贴图的平铺与偏移也按这份 UV 生效；UV 检查模式的棋盘格与导出 GLB 的 `uv_0` 读的是同一套数值。

### 3.4 增量重建签名与镜像联动

- **签名**：`core/engine/clothSignatures.ts` 的 `panelGeometrySignature(project, panelId)` 汇总该片网格构建读取的全部字段：轮廓与内孔边、逐边与片级缝份、`Panel.meshResolutionCm`、片可见性与碰撞层、边记录（含 `arc`）与端点记录，再加全局 `simulation.meshResolutionCm`。`geometrySignatures()` 为每片各算一份，引擎的 `syncFromProject()` 只重建签名变化的那几片；因此改 `SetPanelMeshResolutionCommand` 写入的逐片密度不会牵动其它片。`buildPanelMesh()` 直接读取片字段 `meshResolutionCm`，引擎构建时不传第三个参数，因此逐片密度始终生效；网格边长由 `SetGlobalMeshResolutionCommand` 写入每一片。
- **自动镜像的提交时机**：`SnapshotCommand.execute()` 与 `CommandHistory.execute()` 都调用 `autoSyncMirrors()`，因此结构性命令和拖点/拖片这类自备回滚的命令都能联动。执行前若版型存在 `symmetry` 关系就先深拷贝整份 `Pattern`；命令提交后比较对称对两侧的轮廓指纹（边类型、`arc` 与端点记录），从变化的一侧调用 §1.2 的 `buildMirrorEdges()` 重建另一侧，再由 `prunePattern()` 清掉旧边。两侧都变时按面板 id 字典序取较小者为源，稳定且不会递归。
- **撤销**：发生重建时历史栈里存一个包装命令，撤销先执行原命令的 undo 再整份还原执行前快照，所以一次操作只有一条撤销记录、两侧一起回退。`MirrorPanelCommand` 与 `SyncMirrorCommand` 通过 `skipMirrorSync` 跳过自动联动，由它们自己维护对称关系。

### 3.5 生产物件几何

`pattern/panel/productionGeometry.ts` 是 2D 绘制、3D 合成与物料清单共用的几何层，只读工程数据：

- 袖山高由 `capHeightForArmhole()` 反解：**半条袖山弧**要等于一条袖窿弧。一片袖子的 `capRight` 只缝前片袖窿，`capLeft` 缝后片袖窿。`sleeveCapArcCm()` 量的是整个袖山弧，因此比较时取一半。
- 生成的 `Pattern` 可被用户自由编辑：缝合既由模板写入，也能在 2D 用缝合工具拖两段区间建立，或由【智能】菜单按 `seamCandidates()` 的建议创建（§7.3、06 §4.4）。
- 模板的 `PatternBuilder.seam()` 只写整边配对（`{ t0: 0, t1: 1 }`），子区间配对来自界面命令 `CreateFreeSeamCommand`（06 §3.2）。

> **注**：比较时漏掉取半条袖山弧，袖山只有袖窿的 76%，缝合约束会把它整体拉伸 24%，腋下被撕开。

### 4.2 替换与追加

两个可撤销命令在 `templateCommands.ts`，模板卡片上的【替换版型】【追加版型】分别对应：

| 命令 | 行为 |
| --- | --- |
| `ApplyTemplateCommand` | 整体替换 `project.pattern`；新片沿用工程的第一条面料，没有面料时建一份【棉】 |
| `AppendTemplateCommand` | 先 `detachedPattern()` 复制当前版型的六个集合（新的 `Record`，装着同样的实体引用），再 `appendPattern()` 把模板新生成的实体并入并把新片排在已有版型右侧；id 沿用模板生成时的值。`notches` / `annotations` / `measurements` 不在 `detachedPattern()` 的六份拷贝里，由 `appendPattern()` 就地并入，`PatternBuilder` 不产出这三类，模板因此没有它们 |

两者的 undo 都恢复 `pattern` 与 `fabrics` 快照，因此 `Ctrl+Z` 能完整退回（06 §3.2）。

## 5. 环绕落片（drape）

平面片在进入模拟前需要一个贴合模特的初始位置：`pattern/drape/drapePlacement.ts` 按部位把片环绕到模特表面，基准高度来自 `avatar/landmarks.ts`，因此随体型参数变化。只有带 `drape` 的片走这条路径：带 `placement` 的片平铺到指定位置，两者都没有的手绘片按版型坐标平铺（Z = 0）。

躯干按椭圆柱弯曲，四肢按圆柱弯曲，每个部位一个函数：`wrapTorso` / `wrapArm` / `wrapLeg` / `wrapNeck`，三个四肢函数共用 `wrapTube`。

### 5.1 缺省解析

```typescript
export interface ResolvedDrape { region, anchor, anchorOffsetCm, startDeg, sweepDeg, side, easeCm, pinTop }
export function resolveDrape(panel: Panel): ResolvedDrape
```

| 部位 | 默认锚点 | 默认角跨度 | 默认松量(cm) | 默认 `pinTop` |
| --- | --- | --- | --- | --- |
| `torso` | `shoulderTop` | 180°（半圈） | 1.4 | true |
| `arm` | `shoulder` | 360° | 1.2 | false（靠袖山缝合悬吊） |
| `leg` | `hip` | 360° | 1.2 | true |
| `neck` | `neckTop` | 360° | 0.8 | true |

- 其余缺省：`anchorOffsetCm = 0`、`side = 'right'`、`startDeg = 躯干 −90 其余 0`。
- 躯干角度以模特前中为 0°，四肢以侧面为 0°。
- 缺少 `drape` 的片，`resolveDrape()` 用 `drape/drapeInfer.ts` 的 `inferDrape(name)` 补出参数：片名含袖时归 `arm`、含裤或腿时归 `leg`（两者含左时取左侧）、含领时归 `neck`、含后时归 `torso` 且 `startDeg 270 / sweepDeg −180`、否则归 `torso` 前半圈。这份结果只用于 2D【自动排位】的分行（`autoPlace.ts`）与碰撞层排序的平均松量（`autoLayer.ts`），不会给该片补出 3D 环绕位形（§5 开头）。

### 5.2 角度映射

四种部位共用同一套列映射：

```
topY = landmarkY(anchor) + anchorOffsetCm × 0.01
wy   = topY − (maxY − y) × 0.01              // 纵向：片顶对齐锚点，深度 1:1 下移
u    = (x − minX) / (maxX − minX)            // 横向：整片宽度归一化
θ    = centerRad + sign × (u − 0.5) × |sweep|
```

整片宽度铺满声明的扫掠角，前后片各 180° 时两条侧边都落在 ±90°；纵向不缩放，片顶落在锚点，衣长、袖长按厘米直接换算。

### 5.3 躯干：椭圆柱

```
ring = widestRing(body, topY, bottomY)      // 片高范围内最宽的体截面，8 步采样
topR = mean(ring) + ease                     // 上口：贴体
hemR = max(片宽 / |sweep|, topR)             // 下摆：按布宽放开
R(y) = topR + (hemR − topR) × (topY − wy) / 片高
pos  = (centerX + ring.rx × R/mean(ring) × sin θ,  wy,  ring.rz × R/mean(ring) × cos θ)
```

截面是椭圆（`rx` 左右半宽、`rz` 前后半深），取片高范围内 `rx` 与 `rz` 各自的最大值，与碰撞胶囊同一套体形模型。

### 5.4 四肢：斜置圆柱

```
axisAt = ±(region === 'arm' ? body.shoulderX : body.hipX) + tan(rake) × sign × (topY − wy)
R      = max(片宽 / |sweep|,  肢体半径 + ease)
pos    = (axisAt + R × cos θ,  wy,  R × sin θ)
```

袖、裤、领共用一个 `wrapTube`，三者只有轴向、半径与倾斜不同：`wrapNeck` 的轴在模特中线且不倾斜。

## 6. 脱体与缝合目标

环绕姿态最终生成两份交给模拟的数据：刚性推出的初始位形（`explodeOffBody`）与缝合顶点收拢后的滑动目标（`collapseSeamPairs`），两者都只作用于已算好的位形数组（04 §5.1）。

| 文件 | 作用 |
| --- | --- |
| `explodedLayout.ts` | `explodeOffBody(wrapped, offsetM = EXPLODE_OFFSET_M = 0.02)`：沿模特轴心到该片中心的水平方向把整片刚性推出；中心正好落在模特轴上的片没有径向外方向，退化为向前推出。无应力的由来见 04 §5.1.1 |
| `sewnTargets.ts` | `collapseSeamPairs(pairs, passes = 8)`：把环绕姿态里每对缝合顶点逐步折到中点，得到着装滑动阶段的目标 `dressPositions`，使滑动终点与已闭合的缝纫线不冲突 |

两者的调用方是 `core/engine/initialPose.ts` 与 `mergedCloth.ts`（04 §5.1）。

成对边的角度区间与走向必须一致，同名端点相接的边用 `flip: false`，方向相反的边才用 `true`。

> **注**：走向配错时布料会扭转，`Seam.flip` 是唯一的纠正入口。它由对象标签的【乙边反向】写入（02 §5），改动重建布料并重置模拟；模板侧 `PatternBuilder.seam(…, { flipB })` 是同一个字段的构造参数名。

`tools/flatLayout.ts` 保留 2D 排样到模特前方竖直平面的映射，只供 `clothPreview.ts --stage=flat` 离线查看，不作为模拟初始位形，否则会留下巨大初始应变（04 §5.1.1）。

## 7. 放码、排料与自动化

放码的数据字段在 02 §4.6，这里只讲算法：几何如何解析到某一码、套叠显示画什么、零件怎么排在幅宽内，以及自动排位与缝合建议的依据。

### 7.1 尺码解析与套叠（pattern/grading/grading.ts）

```typescript
/** 尺码表按 seq 升序。 */
export function orderedSizes(project: Project): SizeDef[];
/** 已有尺码表且几何解析到了某一码。 */
export function gradingActive(project: Project): boolean;
/** 当前几何解析到的码，没有尺码表时为 null。 */
export function activeSize(project: Project): SizeDef | null;
/** 该片（轮廓加内孔）解析到 sizeId 后的折线集合，供套叠绘制。 */
export function sizeOutlines(pattern: Pattern, panelId: string, sizeId: string, fromSizeId?: string): Vec2[][];
```

- `sizeOutlines()` 先 `resolveSize(pattern, fromSizeId, sizeId)` 再采样，因此套叠画的是库内几何按档差换算出的各码轮廓，不改工程数据。
- `resolveSize()` 里每个点按自己的档差平移，控制柄走【该边两端档差的均值】，弧边按 §1.2 的规则重解三点弧、其中点随两端档差的均值走（重解不出圆时退回整体平移圆心），所以各码的轮廓仍然连着，不会散成脱开顶点的弧。
- 2D 的【齐码套叠】图层（`displayOptions.gradingOverlay`）对每个非当前码取一组轮廓画在后面，当前码仍然是工程本体（06 §4.1）。
- `resolveSize()`、`ApplySizeCommand`、`SetPointGradingCommand` 与 `validateGrading()` 都在 `core/command/gradingCommands.ts`（06 §3.2）；`validateGrading()` 用 `edgeLength()` 逐码比长度（变短即报【不递增】）、用 `hasSelfIntersection()` 逐码查轮廓自交，两类问题与拓扑问题一起进【检查】菜单（§1.6、06 §4.4）。

### 7.2 排料（pattern/marker/packing.ts 与 markerLayout.ts）

#### 7.2.1 排料算法

`packPanels(items, fabricWidthCm, opts)` 是货架式（next-fit-decreasing）排料，与 2D 的制版排料（§7.4）无关，服务的是裁床幅宽：

```typescript
export interface PackItem { id: string; width: number; height: number; qty: number; }
export interface Placement { itemId: string; x: number; y: number; width: number; height: number; angleDeg: number; }
export interface PackResult { placements: Placement[]; usedLengthCm: number; utilization: number; }
export interface PackOptions { /** 零件之间与货架之间的间距，cm，默认 0.5 */ gapCm?: number;
  /** 放不下时允许转 90°，默认 false；`angles` 未给时据此取 [0] 或 [0, 90] */ allowRotate?: boolean;
  /** 每片可尝试的逆时针旋转角（度），含 0，默认由 `allowRotate` 推出 */ angles?: number[]; }
export function packPanels(items: PackItem[], fabricWidthCm: number, opts?: PackOptions): PackResult;
```

- 零件先按高、再按宽、再按 id 排序；从左到右填满一货架后另起一行，行高取该行最高者。
- 每个零件先对每个允许角度算旋转后的轴对齐包围盒（`rotatedBounds`，对称式 `w·|cosθ| + h·|sinθ|` × `w·|sinθ| + h·|cosθ|`），按先窄、后矮、再小角度的顺序排序；当前行放得下就取最窄者，否则另起一行取能放进幅宽的最窄者，全部放不进才抛【零件【X】尺寸 W×Hcm 超过幅宽 Fcm，无法排料】。`angleDeg` 记在 `Placement` 供 `placePoint` 回放旋转。
- `usedLengthCm` 是沿布方向消耗的长度，`utilization` 是零件面积和 ÷（幅宽 × 用料长）。输入相同则输出相同，没有随机化。

#### 7.2.2 唛架几何

摆放之前的取片与几何在 `pattern/marker/markerLayout.ts`，它是所有唛架输出的唯一几何来源：

```typescript
export interface MarkerSize { id: string; label: string; }
export interface MarkerLayoutOptions { fabricWidthCm?: number; gapCm?: number;
  shrinkPercent?: number; allowRotate?: boolean; angles?: number[];
  sizes?: MarkerSize[]; fromSizeId?: string; }
export interface MarkerPiece { panelId: string; name: string; width: number; height: number;
  outline: Vec2[]; grain: Vec2[] | null; }   // outline 以本片左下角为原点
export interface MarkerPlacement { piece: MarkerPiece; place: Placement; }
export interface MarkerLayout { fabricWidthCm: number; usedLengthCm: number;
  utilization: number; placements: MarkerPlacement[]; }
/** 取可见片的含缝份切割轮廓（`panelOutlineWithAllowance()`），按缩率放大后排进幅宽。 */
export function buildMarkerLayout(pattern: Pattern, opts?: MarkerLayoutOptions): MarkerLayout;
/** 把片内坐标换算到唛架坐标，旋放的片子顺带转回来。 */
export function placePoint(piece: MarkerPiece, place: Placement, p: Vec2): Vec2;
export function placedOutline(entry: MarkerPlacement): Vec2[];
export function placedLabel(entry: MarkerPlacement): Vec2;
```

- 片宽、片高取的是**含缝份**的切割轮廓包围盒，逐边缝份覆盖片级默认值，和模拟用的轮廓是同一条（`panelOutlineWithAllowance()`）。
- `fabricWidthCm` 默认 150、`allowRotate` 在这里的缺省改成 `true`；`angles` 传给 `packPanels` 覆盖这一缺省；没有可见片时抛【没有可排料的版片】。
- 旋转回放在 `placePoint`：按 `Placement.angleDeg` 绕片原点旋转，再平移到旋转后包围盒的左下角，因此任意角度（不止 0/90°）都能正确落进 SVG / DXF。
- 排料图对话框的【旋转角度】提供四档：`0° / 90°（默认）`（不传 `angles`，走 `allowRotate` 缺省）、`仅 0°`（`[0]`）、`0°–90° 每 15°` 与 `0°–90° 每 5°`。选中的角度集同时进入实时的用料报告与 SVG / DXF 导出，导出因此继承对话框里的选择。
- `sizes` 给定时对每码调用 `resolveSize(pattern, fromSizeId, size.id)` 各生成一套片，`panelId` 写成 `面板id@尺码id`，片名后附码标，因此排料、报告、SVG 与 DXF 标签天然区分尺码；不传时只排当前几何。
- SVG 唛架（`io/svgPattern.ts` 的 `exportMarkerSvg`）与 DXF 唛架（`io/dxf/writer.ts` 的 `writeMarkerDxf`）都只消费这一个结果，图片与 DXF 的坐标因此天然一致。

#### 7.2.3 用料报告

`pattern/marker/markerReport.ts` 在唛架结果之上汇总用料数据，导出对话框与 CSV 共用：

- 版片按 `name` 分组合并（同名多片计数量），面积用鞋带公式算 `outline` 的绝对面积。
- 成本只在 `pricePerMeter` 是有限数时计算，为 `null` 时 CSV 不写成本行。
- CSV 固定【项目/数值】列，随后是【版片/数量/面积(m²)】表；数字统一四位小数，成本两位。UI 下载时在字符串前加 `\ufeff` 以兼容 Excel。

### 7.3 自动排位与缝合建议（pattern/auto/）

#### 7.3.1 自动排位

`autoPlace.ts`：

```typescript
export interface PanelOffset { panelId: string; dx: number; dy: number; }
/** 按推断的环绕部位分行、用 layoutRows 排开，返回每片被推移的位移（两位小数）。 */
export function placePanelsAuto(pattern: Pattern, opts?: { gapCm?: number }): PanelOffset[];
```

- 分行顺序固定 `torso → neck → arm → leg`，`gapCm` 默认 4；只统计 `outlineEdgeIds.length >= 3` 的片。
- 环绕部位来自 `pattern/drape/drapeInfer.ts` 的 `inferDrape(panelNameOrShape)`，`autoPlace.ts` 与 `drapePlacement.ts` 共用这一份实现。
- 只给轮廓时按长宽比判定：宽高比 < 0.45 且高 < 45 → `arm`，< 0.55 且高 ≥ 45 → `leg`，其余 `torso`；两处调用都只传片名。

#### 7.3.2 缝合建议

`autoSeam.ts` 的 `seamCandidates()` 给出一批缝合建议，每条是一个 `SeamCandidate`：

```typescript
export interface SeamCandidate { a: SeamEnd; b: SeamEnd; flip: boolean; score: number; reason: string; gatherRatio?: number; }
export interface SeamCandidateOptions { minScore?: number; lengthTolerance?: number; skipExistingSeams?: boolean; }
export function seamCandidates(pattern: Pattern, opts?: SeamCandidateOptions): SeamCandidate[];
```

| 判据 | 取值 |
| --- | --- |
| 语义配对 | `shoulder↔shoulder`、`sideSeam↔sideSeam`、`neckline↔neckline`、`waist↔waist`、`armhole↔sleeveCap` |
| 评分构成 | 语义 0.4 + 长度相似 0.25 + 弦方向一致 0.2 + 曲率（对弦的平均偏离）相近 0.15 |
| 门槛 | `minScore` 默认 0.55、`lengthTolerance`（短/长）默认 0.55，`skipExistingSeams` 默认 false |
| 反向 | 两端点分别相接的距离小于交叉相接的距离时 `flip = false`，否则 `true` |
| 缩缝 | 长短比 > 1.02 时给 `gatherRatio`（保留三位小数），`reason` 里写【吃势 x.x%（建议缩缝）】 |

- `a` / `b` 都是整边区间 `{ t0: 0, t1: 1 }`；每条边只出现在评分最高的那一条建议里。
- `reason` 拼成【语义匹配 shoulder/shoulder，长度比 0.98，方向一致，曲率相近】，其中语义是 `EdgeSemantic` 的原始枚举值（不是中文标签），有吃势时多一段【吃势 8.3%（建议缩缝）】，方向与曲率按 0.8 分界写成【一致/接近】【相近/略有差异】；【智能】菜单的行标签是 `reason · 评分`（评分取两位小数）。
- 菜单接受建议时执行 `CreateFreeSeamCommand`，`flip` 会传下去，但 `SeamOptions` 没有 `gatherRatio` 字段，因此建议里的缩缝比例不会写进缝合，需要时另用 `SetSeamGatherCommand`。

### 7.4 2D 排料（pattern/template/patternLayout.ts）

- `offsetPanel(pattern, panel, dx, dy)` 平移该片轮廓与内孔的全部点，连带 `handleIn` / `handleOut` 与圆弧 `center`，因此形状不变。
- `layoutRows(pattern, rows, gapCm = 4)` 逐行左右排开、行与行依次向下排列，并把每行整体居中对齐到版型原点，保证 2D 视图不重叠；`placePanelsAuto()` 与模板生成都用它。
- `appendPattern(target, source, gapCm = 8)` 把 source 的九个集合逐个并入 target（同 id 覆盖），再把新整片平移到已有版型最右侧之外。

## 8. 版型导出（io/）

三个导出器都只读工程数据，不写回；厘米在 DXF 里换成毫米、Y 轴向上，在 SVG / PDF 里保持厘米。

| 出口 | 入口 | 内容 |
| --- | --- | --- |
| `io/dxf/writer.ts` · `writePatternDxf(pattern, opts)` | 文件 → 导出 → DXF 版型… | 每片一个 BLOCK：净边轮廓、可选 `002-SEAMLNE` 毛边、内部线（`fold` 单列一层）、布纹线、刀口／钻孔、注释文字。`opts.includeSeamAllowance` 决定净／毛，`convention` 换 AAMA／ASTM 层名，`sizes` 出多码，`encoding` 换文本编码 |
| 同上 · `writeMarkerDxf(pattern, opts)` | 文件 → 导出 → 排料图…（格式选 DXF 唛架） | 门幅边界 + 每个摆放一片的闭合轮廓 + 布纹线 + 片名，坐标直接取 §7.2 的排料结果 |

| `io/pdfPattern.ts` · `buildPatternPdf(pattern, opts)` | 文件 → 导出 → PDF 图纸… | 纯文本 PDF（无依赖）：`mode: 'single'`（默认）把可见片打包到一张 A4／A3 上并整体缩放；`mode: 'tile'` 按 §8 的页面网格逐页 1:1 画出该页范围内的矢量内容，页角十字标记、页码与重叠量写在页边。两种模式都写出净边或毛边、布纹线、片名 `P<n>`，返回 `Uint8Array` 由 `downloadBytesFile()` 写入文件 |

- 多码导出：`opts.sizes = { chart, fromSizeId, gapCm }`，`chart` 是 `orderedSizes(project)` 的尺码表，每个尺码先用 `resolveSize()` 解出一份只读副本（不改入参），再按【所有码的最宽组 + `gapCm`】沿 X 平移各自的根 `INSERT`，块名后缀 `-<码标>`，因此读回时片与码一一对应、组与组保证不重叠。没有 `sizes` 时输出与单码完全一致。
- 文本编码：`encoding: 'ascii'` 时 `DxfWriter.pair()` 把所有非 ASCII 值转成 `\U+XXXX`（反斜杠转义为 `\U+005C`，BMP 之外的码点降为 `?`），片名、注释与块名都被转义；`parsePatternDxf` 无条件调 `unescapeDxfValue()`，所以任何 CAD 工具写的同类文件也读得回来。`escapeDxfValue` / `unescapeDxfValue` 是这一格式的唯一实现。
- 布纹线的唯一来源是 `panelBuilder.ts` 的 `panelGrainLine(panel, outline)`：方向取 `grainAngleDeg`，中点取轮廓包围盒中心加 `grainOffset`，总长取 `grainLengthCm`，没给就是短边的 60%。2D 绘制、SVG、PDF、DXF 与排料都用它，导入时 DXF 反过来从这条线的中点与长度还原 `grainOffset`（全零不写）和 `grainLengthCm`。
- PDF 的布局是纯函数 `planPatternPdfLayout(pattern, opts)`，返回每片在页面上的槽位与最终缩放（`scalePtPerCm`），导出对话框据此显示【输出比例 约 1:N】。
- PDF 的 1:1 拼版是另一个纯函数 `planPdfTiling(pattern, { page, marginCm, overlapCm, includeSeamAllowance })`：以可打印区域为页块、相邻页让出 `overlapCm`，返回每页的裁切矩形 `clipCm`、平移量 `offsetPt`（页点 = `offsetPt + cm × 28.3465`）与行列页码 `index / row / col`；空版型返回 `pages: []`，`buildPatternPdf` 仍出一页【No visible panels】。
- 工艺单 PDF 的中文由 `io/pdf/pdfDocument.ts` 的预定义 Adobe-GB1 字体写出（`STSong-Light` + `UniGB-UCS2-H`，每行文字转成 UTF-16BE 十六进制串），不嵌入字体文件、不新增依赖；PDF 图纸仍用 Helvetica，非 ASCII 注释照旧丢弃。两种 PDF 共用 `assemblePdf()` 的多页与 xref 组装。
- 工艺单在生产清单章节后依次写出四张表：**印花**（版片／印花／尺寸(cm)／角度／平铺／不透明度）、**明线**（版片／边／偏移(mm)／行距(mm)／行数／长度(cm)）、**辅料**（版片／名称／类型／直径(mm)／数量／单价／颜色）与**物料清单**（类别／名称／规格／单位／数量／单价／金额）；没有内容时写【无印花】【无明线】【无辅料】。明线长度按 `edgeIntervalLength × rows` 累计，印花的平铺写成【横向 × 纵向】。
- 物料清单的唯一来源是 `pattern/bom.ts`：`buildBom(project)` 跳过隐藏片与隐藏记录，面料按净面积求和、印花数量取平铺乘积、明线换算成米、辅料按 `qty` 计数，只有填了单价的行才给出金额；`bomTotals(rows)` 汇总有单价的行；`bomCsv(rows)` 输出八列（类别／名称／规格／单位／数量／单价／金额／备注），带 UTF-8 BOM 与 CRLF 换行。工艺单与【文件 → 导出 → 物料清单…】对话框都调用同一套函数。
