# 版型系统

这篇讲 2D 图纸如何变成可模拟、可穿在身上的布料网格：曲线怎么采样、轮廓怎么外扩缝份、多边形怎么变成均匀三角形、整套版型怎么由模板生成，以及平面片按什么规则裹到人体上。代码在 `src/pattern/`。

从图纸到网格的顺序固定：`Pattern` 里的点、边、省道与内部线经轮廓采样、缝份偏移、三角化与保形细化得到每张片的 `PanelMesh`；模板生成整套版型，解析摆放把平面片裹到人体上，最后由脱体与缝合目标交给模拟层。

章节顺序依次为：几何内核（§1）、三角化与细化（§2）、版型片构建器（§3）、参数化模板（§4）、环绕落片（§5）、脱体与缝合目标（§6）。

## 1. 几何内核

内核只处理平面几何：向量运算与绕序约定、三次贝塞尔的自适应采样、整条轮廓的缝份外扩，以及外扩自交时的回退路径。

### 1.1 向量与绕序

类型与构造器（`Vec2` / `vec2()`）在 `core/model/types.ts`；`pattern/geom/vec2.ts` 是围绕它们的纯函数集合，`cross` 与 `length` 是文件内私有辅助，对外导出：

```typescript
export const add / sub / scale / dot / distance / normalize / lerp
/** 顺时针法线：(x, y) → (y, −x)。 */
export const perp = (v: Vec2): Vec2 => ({ x: v.y, y: -v.x });
export function polygonArea(poly: Vec2[]): number;
export function ensureCCW(poly: Vec2[]): Vec2[];
export function computeBBox(points: Vec2[]): { min: Vec2; max: Vec2 };
```

- `ensureCCW` 在偏移与三角化之前统一绕序，`perp` 的符号约定因此成立：逆时针多边形的 `perp(边向量)` 指向外侧。
- 这条约定贯穿缝份偏移与 3D 正面朝向（03 §2.3）。

### 1.2 贝塞尔曲线

轮廓的曲线段是三次贝塞尔，四个控制点是边的两个端点加 `c0`、`c1`，控制柄存为制版坐标下的绝对点（02 §4.2）。`pattern/geom/bezier.ts`：

```typescript
export interface CubicBezier2 { p0: Vec2; c0: Vec2; c1: Vec2; p1: Vec2; }
/** 德卡斯特里奥求值。 */
export function evalBezier(b: CubicBezier2, t: number): Vec2;
/** 在 t 处一分为二，两段的并集覆盖原曲线。 */
export function splitBezier(b: CubicBezier2, t: number): [CubicBezier2, CubicBezier2];
/** 递归细分到曲线中点与弦中点的偏差进容差内。 */
export function adaptiveSampleBezier(b: CubicBezier2, tolerance = 0.1, maxDepth = 8): Vec2[];
```

采样密度由偏差容差决定，而不是曲率：

```
subdivide(b, tol, out, depth, maxDepth):
  mid = evalBezier(b, 0.5);  chord = lerp(b.p0, b.p1, 0.5)
  if distance(mid, chord) < tol or depth == maxDepth: out.push(b.p1); return
  [left, right] = splitBezier(b, 0.5)
  subdivide(left, …); subdivide(right, …)
```

- 起点先入列、之后每次只追加终点，因此相邻子段不会重复顶点。
- 调用方是 `sampleEdge()`，容差写死 0.2 cm；直线边直接返回两个端点。

> **注**：没有 `sampleBezier(b, segments)` 这类等参步采样，也没有 `bezierArcLength`——需要弧长时在调用处把采样点连成折线累加（如离线预览 `tools/clothPreview.ts` 的私有 `polylineLength()`）。

### 1.3 缝份偏移

缝份把整条采样后的轮廓折线向外偏移 `Panel.seamAllowanceCm`，得到的多边形直接作为三角化输入。算法是带尖角限幅的角平分线（miter）偏移（`pattern/geom/offset.ts`）：

```
offsetPolygon(polygon, dist)：
  n < 3 → 原样拷贝返回
  对每个顶点 i（取模自动首尾相接）：
    n1 = normalize(perp(curr − prev));  n2 = normalize(perp(next − curr))
    bisector = normalize(n1 + n2)       // 两法线完全反向（180° 折返）时退回 n1
    miterLen = dist / dot(bisector, n1)                       // = dist / cos(θ/2)
    miterLen = sign(miterLen) × min(|miterLen|, |dist| × 4)   // 尖角限幅，防长刺
    result.push(curr + bisector × miterLen)
```

正值外扩逆时针多边形，负值内缩。同文件另有折线版本 `offsetPolyline(points, dist)` 与逐点单位法线 `computePolylineNormals(points)`，被单元测试覆盖但主流程不调用——缝份一律走上面的闭合多边形路径。

> **注**：缝份参与模拟网格，不是一条独立的显示线；改动偏移算法会同时改变模拟粒子分布（02 §4.4）。

### 1.4 自交检测与安全偏移

内偏移或尖角密集处可能自交，检测是 O(n²) 的两两线段相交（跳过相邻边与首尾相接那一对，顶点少于 4 直接返回 false）：

```typescript
export function hasSelfIntersection(polygon: Vec2[]): boolean;
/** miter 结果自交时，退化为逐点沿前后点连线的法线偏移。 */
export function safeOffsetPolygon(polygon: Vec2[], dist: number): Vec2[];
```

- `buildPanelMesh()` 用的就是 `safeOffsetPolygon`。
- 回退路径不做 miter 修正，因此不会自交，但角部尺寸偏小。
- 没有扫描线加速，也不裁掉自交环。

## 2. 三角化与细化

轮廓闭合之后需要两步才成为模拟网格：先由 earcut 得到三角形（§2.1），再把过长的边分裂到接近目标边长（§2.2）。

### 2.1 earcut 集成

```typescript
// pattern/triangulate/triangulate.ts
export interface TriangleMesh {
  positions: Float32Array;   // flat [x0,y0,…]，制版坐标（cm）
  indices: Uint32Array;      // 三角形索引
  vertexCount: number;
  triangleCount: number;
}
/** 闭合多边形三角化，可带洞。 */
export function triangulatePolygon(outline: Vec2[], holes: Vec2[][] = []): TriangleMesh;
```

- 返回值就是 `TriangleMesh`，没有单独的包装类型。
- `holes` 参数保留但目前所有调用方都传空，轮廓之外的镂空待完成。
- 省道与内部线也不参与几何：既不闭合、不生成折叠约束，也不在 2D 绘制，`Dart` 记录只在版片粘贴时产生（02 §4.3）。
- 同文件还提供 `buildAdjacency`（相邻三角形对，弯曲约束的来源）与 `extractBoundaryEdges`（只被一个三角形使用的边）。

### 2.2 保形细化

三角化的边长不均匀，模拟粒子密度需要接近目标边长。`refineMesh(mesh, targetEdgeLength, maxIterations = 8)` 用 conforming 最长边分裂：

```
中点缓存 midpointCache 跨所有轮次 → 同一根边永远复用同一个中点顶点
每轮逐三角形统计需要分裂（长度 > targetEdgeLength × 1.5）的边数：
  0 条 原样保留
  1 条 二分
  2 条 共用顶点处的角三角形 + 另外两块
  3 条 red refinement，切成四个全等三角形
没有新分裂即结束
```

- 因为共享边复用同一个中点，网格在 3D 大变形下不会开裂。
- 轮廓边同样参与分裂（不排斥边界），边界粒子密度与内部一致，缝合约束才能按弧长比例配对。
- 代价是细化后轮廓折线比原采样点更密，但形状不变——新增顶点都落在原边的中点上。

## 3. 版型片构建器

`PanelBuilder` 是一组纯函数，不是类（`pattern/panel/panelBuilder.ts`），把一张片的七类数据一次算齐；轮廓目前只能由模板生成，从零手绘轮廓的工具待完成（06 §4.4）。

```typescript
export interface PanelMesh {
  panelId: string;
  positions2D: Float32Array;    // 细化后的制版坐标（flat x,y），UV 与 3D 位置的来源
  positions3D: Float32Array;    // 同点位形，cm→m、z=0
  indices: Uint32Array;
  uvs: Float32Array;
  vertexCount: number;
  triangleCount: number;
  boundaryEdges: Array<[number, number]>;   // 轮廓边顶点对
  edgeVertexMap: Map<string, number[]>;     // edgeId → 该边采样顶点的粒子索引
}

/** 制版坐标采样 → 缝份外扩 → 三角化 → 细化 → UV → 3D 位置 → 缝合边映射。 */
export function buildPanelMesh(pattern: Pattern, panelId: string, resolutionCm?: number): PanelMesh | null
export function sampleEdge(pattern: Pattern, edgeId: string, reverse?: boolean): Vec2[]
export function samplePanelOutline(pattern: Pattern, panel: Panel): Vec2[]
```

流水线：

```
samplePanelOutline(按 outlineEdgeIds 逐边 sampleEdge，容差 0.2cm)
  → 顶点少于 3 → 返回 null（该片不进模拟）
  → seamAllowanceCm > 0 → safeOffsetPolygon 外扩
  → triangulatePolygon → refineMesh(resolutionCm ?? panel.meshResolutionCm)
  → generateUVs(mesh.positions, computeBBox(offset 后的轮廓))
  → to3D(× 0.01，z = 0)
  → extractBoundaryEdges → buildEdgeVertexMap
```

两个要点：

- 网格边长的归属规则：`resolutionCm` 给定时覆盖 `Panel.meshResolutionCm`，而引擎在 `buildFromProject()` 里总是传全局值（`SimulationConfig.meshResolutionCm`），因此片级数值只在直接调用 `buildPanelMesh` 时生效（04 §5.1）。
- `positions3D` 只是 z=0 的平面位形；真正的着装姿态由 `InitialPose` / `MergedCloth` 负责（04 §5.1），约束静止长度也从那里量出。

### 3.1 缝合边映射

`buildEdgeVertexMap()` 把每条轮廓边的采样点吸附到最近的边界顶点（候选集来自 `boundaryEdges`），相邻重复索引会被去掉。

- 之所以吸附而不是直接用采样点：缝份把网格边界外移过，采样点已经不在网格上。
- 吸附之后有缝份的版型片仍能生成缝合约束（04 §1.3.3 按这个映射取粒子对）。

### 3.2 UV 生成

UV 把制版坐标按该片包围盒归一化，让贴图与版型自然对齐。函数是 `panelBuilder.ts` 内的私有 `generateUVs(positions2D, bbox)`，包围盒由调用方用 `computeBBox(偏移后的轮廓)` 先算好，宽高为 0 时按 1 处理防除零：

```typescript
uvs[i*2]     = (positions2D[i*2]     - bbox.min.x) / (bbox.max.x - bbox.min.x || 1);
uvs[i*2 + 1] = (positions2D[i*2 + 1] - bbox.min.y) / (bbox.max.y - bbox.min.y || 1);
```

- UV 随网格合并成整件服装的一份（`mergedUVs()`），此后静态不变。
- 渲染路径不加载贴图（03 §3.1），因此它当前只影响 UV 检查模式的棋盘格与导出 GLB 的 `uv_0`。

## 5. 环绕落片

平面片在进入模拟前需要一个贴合人体的初始位置：`pattern/drape/drapePlacement.ts` 按部位把片裹到人体上，基准高度来自 `avatar/landmarks.ts`，因此随体型参数变化。

躯干走椭圆环、四肢走斜置圆柱，两者都可开启逐行铺开；未声明 `drape` 的片先走缺省解析。这是解析摆放而不是物理结果，真实贴合交给着装三阶段与后续模拟（04 §5.2）。

### 5.1 缺省解析

```typescript
export interface ResolvedDrape { region, anchor, anchorOffsetCm, startDeg, sweepDeg, side, easeCm, rowWrap, plumb, pinTop }
export function resolveDrape(panel: Panel): ResolvedDrape
```

| 部位 | 默认锚点 | 默认角跨度 | 默认松量 cm | 默认 `pinTop` |
| --- | --- | --- | --- | --- |
| `torso` | `shoulderTop` | 180°（半圈） | 1.4 | true |
| `arm` | `shoulder` | 360° | 1.2 | false（靠袖山缝合悬吊） |
| `leg` | `hip` | 360° | 1.2 | true |
| `neck` | `neckTop` | 360° | 0.8 | true |

- 其余缺省：`anchorOffsetCm = 0`、`side = 'right'`、`rowWrap = plumb = false`、`startDeg = 躯干 −90 其余 0`。
- 躯干角度以人体前中为 0°，四肢以侧面为 0°。
- 没有 `drape` 的片走 `inferDrape(name)`：名字含「袖」→ `arm`（含「左」取左侧）、含「后」→ `torso` 且 `startDeg 270 / sweepDeg −180`、否则 `torso` 前半圈。

> **注**：手写版型只要不改名就能沿用 T 恤那套摆放；改名会改变推断结果。

### 5.2 躯干：椭圆环

```
topY = landmarkY(anchor) + anchorOffsetCm × 0.01
u    = (x − lo(y)) / rowWidth                  // 该点的横向归一化位置，见 §5.3
θ    = (startDeg + u × sweepDeg) × DEG
fromTop = (maxY − y) × 0.01
ring = plumb ? plumbRing(body, wy, topY) : body.torsoEllipseAt(wy)
k    = max(1, rowWidth × 0.01 / ellipseArc(ring, |sweep|))
pos  = ((ring.rx × k + ease) × sin θ,  wy,  (ring.rz × k + ease) × cos θ)
```

四个设计点：

- 截面是椭圆（`rx` 左右半宽、`rz` 前后半深），与碰撞胶囊同一套体形模型。
- `k` 只放大不缩小：布幅比该高度的体表弧长长时保持 `k = 1` 并留余量，短于弧长时也不会把布压进身体。
- `plumb` 取该高度到锚点之间最宽的环（`plumbRing`，8 步采样），宽松连衣裙因此垂直下垂，不会裹住腰臀的凹陷。
- 肩锚定的上身片顶部 `SHOULDER_BAND_M = 0.12` m 内按到中心的角距离平方衰减下沉，模仿肩斜；其余部位不衰减。

### 5.3 逐行铺开（rowWrap）

`rowExtents(mesh)` 把平铺网格按高度分成 `ROW_BINS = 48` 个 bin，记录每行的横向范围：

- 空 bin 取最近的已填充行、顶部再空则回退到下摆，读取时在相邻 bin 间线性插值。
- 开启后，横向归一化 `u` 与 `rowWidth` 都用该行自己的范围，而不是整片的范围；四肢半径取 `max(limbR, rowWidth × 0.01 / spanRad)`。
- 效果是收口的袖子、上窄下宽的裙片能沿每行实际布宽铺开：裙片侧缝闭合，摆围大于臀围时裙摆保持张开。

### 5.4 四肢：斜置圆柱

```
axis = ±(region === 'arm' ? body.shoulderX : body.hipX)      // neck 取人体中线
rake = tan(body.armRakeRad) × sign                            // 放松下垂的手臂向外斜
axisAt(y) = axis + rake × max(topY − wy, 0)
pos = (axisAt + r × cos θ,  wy,  r × sin θ)
```

半径 `limbRadius = max(布宽对应半径, 肢体半径 + easeCm)`，因此宽袖口不会被压回手臂。

## 6. 脱体与缝合目标

环绕姿态最终落成两份交给模拟的数据：刚性推出的初始位形（`explodeOffBody`）与缝合顶点收拢后的滑动目标（`collapseSeamPairs`），两者都只作用于已算好的位形数组（04 §5.1）。

| 文件 | 作用 |
| --- | --- |
| `explodedLayout.ts` | `explodeOffBody(wrapped, offsetM = EXPLODE_OFFSET_M = 0.07)`：沿「人体轴心 → 该片中心」的水平方向把整片刚性推出；中心正好落在人体轴上的片没有径向外方向，退化为向前推出。无应力的由来见 04 §5.1.1 |
| `sewnTargets.ts` | `collapseSeamPairs(pairs, passes = 8)`：把环绕姿态里每对缝合顶点逐步折到中点，得到着装滑动阶段的目标 `dressPositions`，使滑动终点与已闭合的缝线不冲突 |

- 两者的调用方是 `core/engine/initialPose.ts` 与 `mergedCloth.ts`（04 §5.1）。
- 成对边的角度区间与走向必须一致：同名端点相接的边用 `flipB: false`，方向相反的边才用 `true`。

> **注**：走向配错时布料会扭转，`flipB` 是唯一的纠正入口——它由对象标签的「乙边反向」写入（02 §5），改动重建布料并重置模拟。

`tools/flatLayout.ts` 保留 2D 排样到人台前方竖直平面的映射，只供 `clothPreview.ts --stage=flat` 离线查看，不作为模拟初始位形——那会留下巨大初始应变（04 §5.1.1）。
